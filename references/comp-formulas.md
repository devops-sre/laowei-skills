# 赔偿计算口径与法条速查

> 所有公式给的是**全国通行口径**。地方有特别规定的，以 `city-notes.md` 为准；差异处一律**按对劳动者有利的口径主张**，并注明"若当地另有规定，请按其执行"。

---

## 〇、先算时效（最重要，先于一切）

| 项目 | 时效 | 起算点 |
|---|---|---|
| 劳动仲裁一般时效 | **1 年** | 知道或应当知道权利被侵害之日 |
| 拖欠劳动报酬（含加班费、工资差额） | 在职期间**不受 1 年限制** | 劳动关系**终止之日起 1 年内**必须提出 |
| 未休年休假工资（200% 部分） | **1 年普通时效** | 次年 1 月 1 日起（部分省份从第三年起算）→ 实务可主张**近 2 年** |
| 未签劳动合同二倍工资 | 各地口径不一（逐月/整体） | 通常自应当订立之日起满 1 年的次日起算 |
| 公积金追缴 | **无时效** | 可追溯至 1999 年 4 月（C22/C23/C24） |
| 社保补缴 | **无追诉期限制**（行政征收） | — |

> **动作**：时效紧张时，**先提交仲裁申请立案保住时效**，证据可以补交。不要为了凑齐材料而错过时效。

### ⚠️ 时效可以"续命"（详见 `defense-and-risk.md` §二）

**《劳动争议调解仲裁法》第 27 条第 2 款**：时效因**①向对方主张权利、②向有关部门请求权利救济、③对方同意履行义务**而**中断**，**从中断时起重新计算一年**。

```
发一份 EMS 催告函 → 时效重新开始算一年
打一次 12333 投诉 → 时效重新开始算一年
```

**⚠️ 但要注意：下列项目【不是劳动报酬】，不适用"在职期间不受限制"的特殊时效，就是普通 1 年**
- 代通知金（+1）· 经济补偿金（N）· 违法解除赔偿金（2N）· 未签合同二倍工资差额

> 详细中断方法与证据留存见 `defense-and-risk.md` §二。

## 一、基数：解除前 12 个月平均**应得**工资

**公式**
```
月均基数 = 解除/终止前 12 个月内全部货币性收入 ÷ 12
```

**计入**：基本工资、岗位工资、绩效奖金、季度奖、年终奖（分摊到对应月份）、提成、津贴补贴（交通/通讯/餐补/高温）、加班费（多数地区计入，个别剔除）。

**不计入**：报销款、福利性实物、股权激励收益（通常）。

### ⚠️ 工资被拆分时：基数按**实际全部到手**认定（外包核心战场）

外包公司压低赔偿的主要手段不是"不给"，而是**把基数做低**：合同写 4000，实际到账 15000。

**四种拆分套路**

| 套路 | 表现 | 定性 |
|---|---|---|
| 私户/微信走账 | 公账发基本工资，大头由法人、财务、老板亲属的个人卡/微信转 | "合理避税"约定**无效** |
| 发票报销抵工资 | 其余部分要你找发票报销领取 | 公司无法证明报销真实性 → 计入工资 |
| 关联公司/亲属账户代发 | 老板母亲名下企业、关联公司同期另发一笔 | 付款同期性 + 亲属关系 → 计入工资 |
| 个体户/服务费 | 让你注册个体户，改付"服务费" | ⚠️ 涉**虚开发票**（刑法 205 条），立即停止配合 |

**法律依据**：以"合理避税"为名约定低工资，同时违反个税征管与社会保险的**强制性规定**，
属恶意串通损害国家税收与社保基金利益 → **该约定无效**，按劳动者**实际全部到手工资**认定。

**实证**：朝阳某案 —— 合同写 3000 元，私户每月固定转 17000 元，**连续 12 个月** → 法院认定月均 **20000 元**。

**证据链组装（四选三即可形成闭环）**
```
① 银行流水（实收总额，含私户、微信）
② 个税申报数（公司自己报的，反证力最强）
③ 工资条 / 薪资系统（结构说明）
④ 聊天记录（公司承认"月薪 X 万"、法人索要银行卡号）
```
做成**月度对照表**（公账 / 私户 / 报销 / 实收合计 / 个税申报 / 社保基数），
一表同时成立三笔账：赔偿基数差、社保基数差、公积金基数差。

> ⚠️ **反向提醒**：若你曾**主动配合**拆分（提供亲属账户、代签劳务协议、找发票冲账），
> 会面临工资标准举证困难、贷款审核受影响、**被追缴个税及滞纳金**的风险。
> 现在还在配合的，**从今天起留存"公司要求我这么做"的证据**，证明被动配合。
> 完整方法见 `full-chain-playbook.md` §2。

**三条修正规则**
1. 工作不满 12 个月的 → 按**实际月数平均**；
2. 月均**低于当地最低工资**的 → 按**最低工资**计（劳动合同法实施条例第 27 条）；
3. **降薪后离职的，按降薪前正常工资标准计算**（C10 南昌中院终审明确：不按降薪后实发）。

**封顶规则**（劳动合同法第 47 条第 2 款）
```
若 月均基数 > 当地上年度职工月平均工资 × 3
→ 基数按 3 倍计，且支付年限最高不超过 12 年
```

> ⚠️ 互联网从业者月薪 3 万以上，在一线城市是否触发封顶要具体查当地社平工资的 3 倍（如北京 2025 年口径约 3.5 万左右）。触发封顶时，**2N 的年限被砍到 12 年**，但金额仍可能很高。

## 二、N / N+1 / 2N

### N（经济补偿）— 劳动合同法第 47 条
```
N = 本单位工作年限折算的月数
   满 1 年 → 1 个月
   6 个月以上不满 1 年 → 按 1 年（1 个月）
   不满 6 个月 → 0.5 个月
经济补偿 = N × 月均基数
```
**适用**：协商解除（公司提出，第 36/46 条）、第 40 条无过失性辞退、第 41 条裁员、**第 38 条被迫解除**、劳动合同期满终止且单位不同意续订或降低条件续订。

### +1（代通知金）— 劳动合同法第 40 条 + 实施条例第 20 条
```
+1 = 上一个月工资（不是 12 个月平均）
```
**仅在**：依第 40 条（医疗期满不能从事原工作/不能胜任经培训或调岗仍不能/客观情况重大变化协商不成）解除，且**未提前 30 日以书面形式通知本人**时支付。
> 已提前 30 天书面通知，或已额外支付 1 个月工资的，**不再支付 +1**。
> **违法解除（2N）不存在 +1**——二者性质不同，不能叠加为 2N+1。

### 2N（违法解除赔偿金）— 劳动合同法第 87 条
```
赔偿金 = 2 × 经济补偿 = 2 × N × 月均基数
```
**适用**：用人单位违反本法规定解除或终止劳动合同，劳动者**不要求继续履行** or 劳动合同**已不能继续履行**。

**另一个选项：要求继续履行**（第 48 条）
- 优点：恢复劳动关系 + **补发仲裁诉讼期间的全部工资**（往往比 2N 更多）
- 缺点：周期长，且实践中"信任基础破裂"常导致法院不支持
- **策略**：2N 与恢复劳动关系**择一主张**，但可以在申请书中把 2N 作为主请求 —— 若公司恶意注销、岗位已撤销，2N 更稳

### 定性速查

| 公司的说法 | 真实定性 | 你主张 |
|---|---|---|
| "业务调整/降本增效，给 N+1" | 非法定事由 → 违法 | **2N** |
| "部门整体外包，客观情况重大变化" | 不成立（C3） | **2N** |
| "你严重违纪"（证据不足/处罚过重） | 违法（C1/C2） | **2N** |
| "裁员"，但没提前 30 天说明、没报告 | 程序违法（C4） | **2N** |
| "客观情况重大变化"，提前 30 天通知了 | 可能合法 | **N**（争取 2N） |
| "你自己辞职吧" | 自愿离职 | **0** → 绝不签 |
| 欠薪 / 未缴社保，你被迫解除 | 你依法行使解除权 | **N** |

### ⚠️ 项目制合同 vs 固定期限合同（外包最容易踩的定性分叉）

**先翻合同第一行的期限条款 —— 它决定了你能要 N 还是 2N。**

| 合同类型 | 项目结束的法律后果 | 你能主张 |
|---|---|---|
| **以完成一定工作任务为期限**（写明"本合同至 XX 项目结束为止"） | 属劳动合同**终止**，不是解除 | **N**（实施条例第 22 条：此类合同因任务完成而终止的，用人单位应支付经济补偿） |
| **普通固定期限**（写 2021.6–2024.6） | 项目结束 **≠ 合同到期**，公司无权终止 | 直接辞退 → **违法解除 → 2N** |
| **无固定期限** | 同上 | **2N** |

> **公司套路**：口头说"项目结束你就自动结束了，没有补偿"。只有项目制合同才谈得上"终止"，**而且终止也得给 N**。普通固定期限合同说这话，就是违法解除 → 2N。

**判断口诀**：合同里有没有"以完成 XX 项目为期限"这类表述？**没有** → 项目结束与你无关 → 辞退就是 2N。

### ⚠️ "假待工、真待岗"（外包公司最核心的套路，务必识别）

劳动法里**没有"待工"这个概念，只有"待岗"**。外包公司故意混用：

| | 真正的待岗 | 外包公司的"待工" |
|---|---|---|
| 依据 | 非因劳动者原因**停工停产** | 仅仅是"项目结束了，等新项目" |
| 是否打卡 | **不打卡，放假在家** | **要求考勤打卡**，或安排"培训" |
| 是否安排工作 | 无 | 无具体任务，但人在岗 |
| 待遇 | 第 1 月全额，之后最低工资 80% | 直接按最低工资发 |
| 目的 | 经营困难时的临时措施 | **逼你自己走，不给赔偿** |

**法律要点**：待工条款的效力，取决于劳动合同中"退项后至新项目确定前按最低工资发放"这一约定是否有效。**目前司法判例（尤其北京地区）普遍不支持此类条款**，法院倾向认定待工非法，公司须支付**全额工资**。

**应对三选一**
1. **想继续干** → 书面拒绝待工安排，坚持按原合同提供劳动；公司实际扣减工资后，仲裁主张**工资差额**
2. **想尽快走** → 先书面提出**被迫离职**，再仲裁主张 **N**
3. **公司有劳务派遣资质 / 甲方直接考勤管理** → 追加甲方为共同被申请人，主张**假外包真派遣**或**混同用工连带**

> 来源：曲良敏律师《外包公司搞假"待工"真"待岗"，打工人如何应对？》 https://www.toutiao.com/article/7623384701054632482

## 三、待岗（停工停产）工资 — 工资支付暂行规定第 12 条

```
第 1 个工资支付周期内（通常第一个月）：
    按劳动合同约定标准支付【全额工资】

超过 1 个工资支付周期：
    提供了正常劳动 → 不低于【当地最低工资标准】
    未提供正常劳动 → 按【不低于当地最低工资标准的 80%】支付生活费
```

**差额主张**
```
待岗工资差额 = 应发（全额 / 最低工资 / 最低工资×80%） − 实发
```

**抗辩要点**
- 待岗是**变更劳动合同**（岗位、工资待遇），依第 35 条**须协商一致并书面**；
- **待岗事由与期限由用人单位举证** —— 公司拿不出真实停工停产证据（仅"项目结束"不算），待岗不合法 → 按**原工资标准**补差额；
- 待岗期间劳动关系存续，**社保必须继续缴**；
- 违法待岗 + 欠发生活费 → 可同时构成第 38 条"未及时足额支付劳动报酬"，**被迫解除拿 N**。

## 四、单方降薪差额

**依据**：第 35 条（变更须协商一致并书面）+ 第 38 条第 1 款第 2 项（未足额支付报酬）+ 第 46 条第 1 项（支付经济补偿）。

```
降薪差额 = Σ（降薪前月工资标准 − 降薪后月实发）  逐月累加
```

**认定"未足额支付"的常见情形**
- 直接下调基本工资
- 绩效/提成规则单方变更导致收入降低（C12、C13）
- 长期固定发放的补贴改为凭票报销或停发（C14）
- 取消全勤奖、绩效清零

**关键动作**：**降薪当月就要书面提异议并留痕**。沉默不影响实体权利（C10 明确"长期未提异议视为合意"不成立），但异议记录是胜诉的加速器。

## 五、加班费

**法定标准**（工资支付暂行规定第 13 条 / 劳动法第 44 条）
```
日工资   = 月工资 ÷ 21.75        （21.75 = (365−104) ÷ 12）
小时工资 = 日工资 ÷ 8

工作日延时   ≥ 150%
休息日       ≥ 200%（安排补休的可不支付）
法定节假日   ≥ 300%（不能用补休替代）
```

**举证规则**（司法解释一第 42 条）
1. 劳动者先就**加班事实存在**举证，或证明**加班证据由公司掌握**；
2. 公司应当提供而拒不提供 → **推定劳动者主张成立**。

**互联网从业者的证据组合**（避免 C18 的坑）
| 层次 | 证据 |
|---|---|
| 时间锚点 | 打卡记录 / 门禁记录 / VPN 登录日志（录屏保存） |
| 实际工作 | 代码提交记录、工单/需求系统操作、会议记录、文档编辑时间、企业微信消息 |
| 安排来源 | 领导在工作群 @ 你、项目排期表、发版计划、周报 |
| 公司掌握考勤 | 公司不提供考勤 → 主张举证责任倒置（C15） |

## 六、未休年休假工资

**法定天数**（职工带薪年休假条例第 3 条）—— 按**累计工作年限**（含其他单位工龄）
```
满 1 年不满 10 年 → 5 天
满 10 年不满 20 年 → 10 天
满 20 年           → 15 天
```

**折算**（企业职工带薪年休假实施办法第 5 条 / 第 12 条）
```
当年折算天数 = (当年在本单位已过日历天数 ÷ 365) × 全年应享天数   （不足 1 整天的部分不计）
离职时折算   = (当年已过日历天数 ÷ 365) × 全年应享天数 − 已休天数
```

**金额**
```
日工资 = 月工资 ÷ 21.75   （月工资 = 前 12 个月平均，剔除加班费）
未休年假应补 = 日工资 × 200% × 未休天数     ← 100% 已随正常工资发放
```

**要点**
- **团建、集体出游不等同年休假**（C29）
- "年底清零"类规章制度无效
- **时效**：200% 部分适用 1 年普通时效 → 实务只主张**最近 2 年**

## 七、年终奖 / 十三薪

**五分法判断把握度**
| 类型 | 例子 | 把握 |
|---|---|---|
| 薪金类 | 十三薪、年底双薪、年薪制约定比例 | ★★★★★ 按在职月数**折算必给** |
| 考核类 | 绩效年终奖 | ★★★☆☆ 适用 183 号：非本人过失离职 + 完成年度工作 + 公司不能证不合格 → **支持** |
| 提成类 | 项目提成、业绩奖金 | ★★★★☆ 完成即应发 |
| 奖励类 | 优秀员工奖 | ★★★☆☆ 已获称号即应发 |
| 福利类 | 年会红包、抽奖 | ★☆☆☆☆ 单位自主 |

**折算公式（薪金类）**
```
应得十三薪 = 约定金额 × (当年在职月数 ÷ 12)
```

## 八、住房公积金差额

**基数与比例**
```
月缴存额（单位）= 职工上一年度月平均工资 × 单位缴存比例（5%~12%，各市规定）
月缴存额（个人）= 同基数 × 个人缴存比例（通常与单位同比例）
```
- 基数受各市**上下限**约束（上限通常为当地社平工资 3 倍，下限为最低工资）
- **基数认定以个税申报工资为准**（C25）→ 个税 App 明细就是铁证

**追缴路径**：公积金中心投诉 → 核查通知书 → **责令限期办理决定书** → 逾期**申请法院强制执行**

**现金主张**：公积金不属劳动仲裁受案范围，**不能写进仲裁请求**；只能走行政追缴（进个人账户）。

## 九、社会保险

**不能做的**：仲裁/诉讼请求"判令补缴社保" → **不予受理**（C21）
**能做的**：
1. **行政途径**（首选）：向税务部门（12366）或社保稽核/劳动监察投诉 → 责令补缴 + **滞纳金万分之五/日** + 欠缴额 **1~3 倍罚款**；逾期可**划拨、查封、拍卖**（社会保险法第 63、86 条）
2. **第 38 条第 1 款第 3 项**：以"未依法缴纳社保"为由**被迫解除 → 主张 N**
3. **损失赔偿诉讼**：因未缴/断缴导致无法领取失业金、无法报销医疗费、无法享受生育待遇的**实际损失**

> ⚠️ **地方差异**：部分省市要求"**未缴纳**"才触发第 38 条，"**未足额缴纳**"（按最低基数）可能不支持。北京、上海、广东、江苏口径不同 → **先查当地口径**，不确定就把"未足额"作为辅助理由，主理由用"未足额支付劳动报酬"或"未提供劳动条件"。
> 更有把握的替代路径：**同时主张"未按实际工资申报缴费基数，违反法律强制性规定"**，并结合社保稽核的行政施压。

## 十、竞业限制补偿金

- 有约定 → 按约定（约定过低可请求调整）
- **未约定**补偿但劳动者履行了竞业义务 → 可要求按**离职前 12 个月平均工资的 30%** 按月支付，且**不低于当地最低工资标准**（司法解释一第 36 条）
- 用人单位**连续 3 个月未支付**补偿 → 劳动者可请求**解除竞业限制协议**（司法解释一第 38 条）
- 约定"仲裁诉讼期间不计入竞业期限" → **无效**（指导案例 184 号）

## 十一、其他容易漏掉的钱

| 项目 | 依据 | 口径 |
|---|---|---|
| 未签书面劳动合同二倍工资 | 第 82 条 | 用工满 1 个月次日起，最长 **11 个月** |
| 违法约定试用期赔偿金 | 第 83 条 | 已履行超法定试用期部分 × 转正工资 |
| 离职未出具离职证明的损失 | 第 89 条 | 造成损害的赔偿（常表现为无法入职新单位） |
| 未提前 30 日通知工会 | 第 43 条 | 程序瑕疵，**补正前解除违法** |
| 工资未结清 | 第 9 条（工资支付暂行规定） | 解除或终止时**一次付清** |
| 加班费 | 第 44 条 | 见 §五 |
| **加付赔偿金 50%~100%** | **第 85 条** | ⭐ 未足额支付劳动报酬、低于最低工资、不付加班费、不付经济补偿的，由劳动行政部门**责令限期支付；逾期不支付的，责令用人单位按应付金额 50% 以上 100% 以下加付赔偿金**。这条是**监察投诉的核心杀伤力**，必须在投诉书里写明 |

> **第 85 条的正确用法**：走劳动监察（12333）时，请求事项不能只写"责令支付工资"，要写
> "责令限期支付，并**依法加付 50%~100% 的赔偿金**"。公司一算账，多赔一半，通常立刻付款。

## 十二、一裁终局门槛（决定能不能阻断公司拖延）

**劳动争议调解仲裁法第 47 条**
```
追索劳动报酬、工伤医疗费、经济补偿或者赔偿金，
不超过当地月最低工资标准 12 个月金额的争议
→ 裁决自作出之日起生效（终局）
   用人单位不得起诉，只能向中级人民法院申请撤销（事由极窄）
```

**用法**
- 若总金额略高于门槛 → **拆分请求**：把金额大的一项单独列，或主动放弃超出部分换取终局
- 门槛随当地最低工资浮动：如北京月最低工资 2420 元 → 门槛约 **29040 元**；深圳 2360 元 → 约 **28320 元**
- 具体数值查 `city-notes.md`
