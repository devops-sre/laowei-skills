## 通道总览

| 通道 | 电话 / 入口 | 受理范围 | 费用 | 法定时限 | 强制力 |
|---|---|---|---|---|---|
| 劳动监察 | 12333 / 12345 / **国务院客户端小程序 → 全国根治欠薪线索反映平台** | 欠薪、加班费、未签合同、违法解除责令整改 | 免费 | 5 日答复受理，60 日办结（实务常 7~15 天见效） | 责令改正 + 罚款 + 失信记录 + **第85条加付50%~100%赔偿金** |
| 社保稽核 / 税务 | 12366 / 12333 | **社保补缴、基数差额** | 免费 | 无追诉期 | 滞纳金万分之五/日 + 1~3 倍罚款 + 划拨 |
| 住房公积金中心 | 12329 | **公积金补缴/追缴** | 免费 | **无时效** | 责令限期缴存 → **法院强制执行** |
| 劳动仲裁 | 当地劳动人事争议仲裁委员会 | 赔偿金、补偿、工资差额、加班费、年假、年终奖 | **免费** | 45 日（可延 15 日） | 一裁终局 / 申请法院执行 |
| 人民法院 | 立案庭 / 在线法院 | 起诉、支付令、保全、先予执行、强制执行 | 诉讼费低（劳动案件 10 元起） | 一审 3~6 月；支付令 15 日 | 冻结、划拨、限高、失信 |
| **税务违法检举** | **12366** / 税务局官网"税收违法行为检举"平台 | 拆分工资、体外发薪、私户走账、未足额申报个税 | 免费 | 实名举报可获进度反馈 | ⭐ 补税 + 滞纳金 + 0.5~3 倍罚款，情节严重认定偷税 |
| **个税申诉** | 个人所得税 App → 收入纳税明细 → 申诉 | 申报收入与实际不符、"被任职" | 免费 | — | 税务机关会向公司核实 |
| 法律援助 | 12348 | 符合条件者免费律师 | 免费 | — | — |

> **税务线的原理**：金税四期已实现**个税申报、社保缴纳、银行流水、企业工资成本四流交叉比对**。
> 实务口径：个税工资与社保基数差异 **> 10% 即触发预警工单**，无需人工抽查。
> 这让"按最低基数缴社保"从"普遍现象"变成了"系统自动标记的风险点"。
> ⚠️ 但税务举报**不可逆**，建议先仲裁立案，把它作为后手牌。详见 `full-chain-playbook.md` §4.1。

## §1 劳动监察（最快的行政施压）

**适合**：公司还在正常经营、怕行政处罚、金额不算特别大。

**步骤**
1. 打 **12333** 或 **12345** 转属地劳动保障监察大队，问清线下窗口地址与所需材料
2. 现场提交《投诉书》+ 证据复印件，**索要《受理回执》**（关键凭证）
3. 监察员约谈公司，可下达《劳动监察责令改正决定书》
4. 公司逾期不改正 → 罚款、记入信用记录、移交法院强制执行

**投诉书要点**
- 被投诉单位：**全称 + 统一社会信用代码 + 注册地 + 实际经营地**（必须准确，否则不受理）
- 投诉请求分条列明（每一项写金额）
- 事实简明，附证据目录

**话术（窗口）**
> "我要投诉 XXX 公司未及时足额支付劳动报酬（/未依法缴纳社会保险费/违法解除劳动合同）。我有劳动合同、银行流水、个税明细和公司的待岗通知。请求依法责令其限期支付并整改。"

**注意**：监察**不处理**"经济补偿金/赔偿金争议"的实体裁判（属仲裁范围），但可以就**欠薪、未缴社保**强力介入。所以监察是**施压工具**，钱最终从仲裁/调解里拿。

## §2 社保补缴与基数差额（12366 + 12333）

**原理**：社保已由**税务部门统一征收**。投诉后税务/社保稽核可**核定欠缴时段、责令补缴、加收滞纳金、处以罚款**，逾期可**申请法院划拨、查封**。

**步骤**
1. **先发《社保补缴催告函》**（EMS，保留单号）—— 证明你主动主张过权利
2. 打 **12366**（税务）投诉："公司未按实际工资申报社保缴费基数，请依法核定并责令补缴"
3. 同步向属地**社保稽核部门 / 劳动监察**提交书面《社保补缴投诉书》
4. 提交材料：身份证复印件、劳动关系全套证据、**社保缴费明细**、个税申报工资、催告函及快递记录
5. **索取受理回执**，跟进处理进度

**公司否认劳动关系时**
> 先申请**劳动仲裁确认劳动关系**（免费）→ 拿到生效裁决书 → 持裁决书去税务/社保窗口申请核定补缴。

**诉求写法**
> "请求依法核定 20XX 年 X 月至 20XX 年 X 月的社会保险缴费基数（应按本人实际工资 X 元申报），责令被投诉单位限期补缴差额，并依法加收滞纳金。"

**关键弹药**：个税 App 的收入纳税明细 —— 公司自己申报的工资数，与社保基数一比对，差额一目了然。

## §3 住房公积金追缴（最容易被忽略、性价比最高的一笔）

**为什么值得做**
- **无时效限制**，可追溯至 1999 年 4 月（C22、C23、C24）
- 公司按最低基数缴 → 差额按**单位应缴部分的比例**补，通常 5%~12%
- 外包公司普遍**按最低工资缴或不缴**，工作 3~5 年的人，这一笔常在 **2 万~8 万**
- 钱**进你自己的公积金账户**（可提取/可贷款），不是给公司

**步骤**
1. 公积金 App / 官网打印**缴存明细**（起止月份、基数、比例、月缴额）
2. 个税 App 导出各年度**收入纳税明细**（证明真实工资）
3. 向单位**注册地或经营地**的住房公积金管理中心提交《补缴投诉书》
   - 携带：身份证、劳动关系证明（合同/离职证明/裁决书）、工资证明、缴存明细
4. 中心立案 → 发《核查通知书》给单位 → 单位申辩 → 作出**《责令限期办理决定书》**
5. 单位逾期仍不缴 → 中心**申请人民法院强制执行**

**单位常见抗辩与你的回击**
| 单位说 | 你回 |
|---|---|
| "已过诉讼时效" | 公积金追缴不适用民法典/行政处罚法/调解仲裁法的时效规定（C22）；国家层面明确不设时效（C24） |
| "劳动合同没约定公积金" | 缴存是**法定强制义务**，不需双方约定，也不得协商免除 |
| "工资条里没扣，员工知情" | 职工是否主张权利不影响单位法定义务的履行 |
| "经营困难" | 缴存具有强制性，**不得以经营困难为由拒绝履行** |
| "个人部分没补" | 责令补缴的是单位应缴部分，**个人部分未缴不免除单位义务**（C25） |

### 公积金追缴的【真实】时间线（务必有心理准备）

网上常有人说"投诉完 30 天到账"，那是**顺利情形**。看深圳市住建局的官方答复（原文口径）：

```
受理投诉
  ↓  60 日内，公积金中心对未整改单位作出【处理决定】
处理决定送达单位
  ↓  单位享有 60 日行政复议期 + 6 个月行政诉讼期
  ↓  若单位复议或起诉 → 按复议/判决结果确定行政决定是否生效
期满未复议、未起诉、也未整改
  ↓  公积金中心在 3 个月内【申请法院强制执行】
法院执行（时限以法院答复为准）
```

**结论：顺利 1~3 个月；单位硬扛到底，可能 8~12 个月甚至更久。**
（上海相对快：15 日内审核 → 责令限期补缴 → 单位 5 日内补缴 → 1~3 工作日到账，整体常 1~2 个月。）

**三条实务提醒**
1. **案件办结前，绝对不要注销你的公积金个人账户** —— 注销了补缴款无处可入（深圳住建局明确提示）
2. 补缴款**单位部分 + 个人部分**都要补（个人部分本应从你工资里扣），最终**全部进你的公积金账户**，可提取可贷款
3. 可用"深圳市住房和建设局"公众号或当地公积金 App 的**执法进度查询**跟进，不必反复打电话

> 来源：深圳政府在线（深圳市住房和建设局答复） https://www.sz.gov.cn/hdjlpt/detail?pid=2503245

### 线上投诉入口（2026 年最省事的三个）
1. **全国住房公积金小程序**（微信/支付宝搜）→ 投诉举报 / 维权申诉入口，全程线上可查进度
2. **当地公积金中心公众号 / App** → 维权投诉入口
3. **12329** 转人工 → 说明公司名称、漏缴时段、基数，按要求补材料

> 线下必须去**公司注册地**的公积金中心，不是你上班地或居住地。

**⚠️ 重要**：公积金**不能写进劳动仲裁请求**（不属受案范围），必须走行政投诉。

## §4 劳动仲裁（要钱的主战场）

### 立案
- **管辖**：用人单位所在地 或 劳动合同履行地（实际工作地）的劳动人事争议仲裁委员会 —— **选对你有利的**（各地最低工资、社平工资、裁审口径不同）
- **费用**：**免费**
- **时效**：1 年（见 comp-formulas §〇）
- **材料**：仲裁申请书（按被告人数 +2 份）、身份证复印件、企业信用信息公示报告（工商登记信息）、证据目录及证据
- **受理**：5 日内决定是否受理；**45 日内裁决**，复杂可延 15 日

### 申请书结构（决定成败）
```
申请人：姓名、身份证号、住址、联系电话
被申请人：公司【全称】、统一社会信用代码、住所地、法定代表人、联系电话
（如主张甲方连带责任 → 列为第二被申请人 / 第三人）

仲裁请求（必须分项、每项写金额）：
  1. 请求确认申请人与被申请人 20XX.X.X—20XX.X.X 存在劳动关系；
  2. 请求裁决被申请人支付违法解除劳动合同赔偿金 XXX 元（2 × N × 月均工资 X 元）；
  3. 请求裁决被申请人支付 20XX.X—20XX.X 待岗期间工资差额 XXX 元；
  4. 请求裁决被申请人支付 20XX.X—20XX.X 期间加班费 XXX 元；
  5. 请求裁决被申请人支付未休年休假工资 XXX 元；
  6. 请求裁决被申请人支付 20XX 年度年终奖/十三薪 XXX 元；
  7. 请求裁决被申请人支付工资差额 XXX 元；
  8. （若主张甲方连带）请求裁决第二被申请人对上述款项承担连带支付责任。

事实与理由（按时间线写，每段挂证据编号）：
  入职 → 换签/管理情况 → 退项待岗 → 降薪 → 解除 → 我方异议 → 协商未果
  法律论证：为何构成违法解除 / 为何工龄应合并 / 为何基数应为 X 元

此致
XXX 劳动人事争议仲裁委员会
```

**写请求的三个技巧**
1. **工龄确认单独列为第 1 项**（尤其有换签的），这是后面所有金额的地基
2. **金额往高里算，但每项都要有计算式** —— 仲裁员/法官看到算式才敢支持
3. **想用一裁终局** → 控制单项金额 ≤ 当地月最低工资 × 12，并在申请书中注明"请求依法适用一裁终局"

### 加速三件套
| 工具 | 何时用 | 怎么做 | 效果 |
|---|---|---|---|
| **一裁终局** | 单项 ≤ 月最低工资 × 12 | 申请书注明；拆分请求 | 裁决作出即生效，**公司不能起诉** |
| **先予执行** | 追索劳动报酬，权利义务明确，不执行将严重影响生活 | 向仲裁委/法院提交申请 | **无需担保**，裁决前先拿部分钱 |
| **财产保全** | 公司有转移资产迹象 | 立案时同步提交保全申请 + 担保（可买保全责任险，费用低） | 48 小时内裁定，**冻结账户 → 老板主动来电** |

### 开庭与调解
- 仲裁庭**先行调解**是法定环节 → 这是你最好的收钱窗口
- 调解书**签收即生效**，公司不能上诉 → 但必须写清**付款期限 + 逾期违约条款**
- **底线：钱到账才签字**。可约定"当场转账"或"3 日内到账"

## §5 谈判与调解话术（把筹码变成钱）

### 报价策略
```
开口价 = 激进档（含全部项目、按最有利口径）
落点价 = 合理档（砍掉把握低的项目，保留 2N 主体）
底线价 = 保守档（只保留违法解除赔偿金 + 工资差额）
```

### 三条施压线（同时点着）
1. **税务 12366**：未按实际工资申报社保基数
2. **公积金 12329**：未足额缴存，无时效，可强制执行
3. **劳动监察 12333**：欠薪、违法解除

> 让公司法务算一笔账：你的赔偿金 8 万，而社保公积金补缴 + 滞纳金 + 罚款可能是 15 万，还要记入信用记录。**这时 8 万就是最便宜的选项。**

### 话术模板

**开场（对 HR）**
> "我不希望走到仲裁。我的诉求很清楚：依法支付违法解除赔偿金 X 元 + 待岗工资差额 Y 元 + 未休年假 Z 元，一共 W 元。这个数字我按法律规定算过，附上计算式。社保和公积金的基数差我已经整理好材料，一旦提交，涉及的不只是我一个人。"

**公司说"公司困难，只能给 N"**
> "N 是协商一致解除的标准。但你们是以『退项』名义单方解除的，部门外包不构成客观情况重大变化，这一点顺义法院判过（途家案）。要走下去是 2N，差一倍。今天是 N+3，明天就是 2N 加执行。"

**公司说"你签了自愿离职"**
> "那份文件是在待岗期间、在未告知法律后果的情况下签署的，我保留依法主张的权利。而且你们在待岗期间通过监控倒查、拆分累计违纪行为制造解除条件，这一点上海宝山法院有过明确认定。"

**公司说"要走流程就走，我们不怕"**
> "那我把社保基数差和公积金一并向税务和公积金中心提交。公积金追缴没有时效，可以追到入职第一个月，而且责令之后可以直接申请法院强制执行。这部分跟我的赔偿金是两笔账。"

**调解桌上（对仲裁员说）**
> "我愿意调解，但要求：（1）款项 3 日内到账；（2）调解书载明逾期不付按全额 2N 执行；（3）公司同步出具离职证明、办理社保和公积金转移。钱到账我再签字。"

### 三个必须守住的原则
1. **不签"自愿离职""个人原因""放弃一切权利"**
2. **钱到账才签调解协议**（签字后公司不履行，你还得走执行）
3. **离职证明、社保公积金转移、档案一并写进协议**（否则影响下一份工作）

## §6 法院阶段

### 6.0 ⚠️ 财产保全 —— 时机是全部关键（不要等裁决生效）

**最常见的致命错误**：以为"仲裁赢了再去冻结公司账户"。
**错了** —— 等裁决生效（45 天 + 15 天起诉期，甚至一两年诉讼）公司早就把钱转走了。

**正确时机**：
```
【最优】仲裁立案【同步】提交保全申请
【次优】仲裁审理过程中，发现转移迹象时立即申请
【最差】裁决生效后 —— 此时只能申请强制执行，钱可能已经没了
```

> 实务金句：**"让对方收到仲裁通知时，账户已然冻结。"**

#### 两种路径

| 类型 | 怎么用 | 担保 | 时限 |
|---|---|---|---|
| **仲裁中保全**（主流） | 向**仲裁委**递交《财产保全申请书》，由仲裁委转交有管辖权的法院 | 一般需担保；**经济困难可提供保证人担保**；多地法院对劳动报酬案件**减轻或免除担保** | 法院**48 小时内**裁定 |
| **仲裁前保全**（紧急） | **直接向法院**申请，不经仲裁委 | **必须提供担保** | 48 小时内裁定；**保全后 30 日内必须申请仲裁**，否则解除 |

**管辖**：用人单位住所地 或 被保全财产所在地**基层法院**（2026 年北京口径：不必与仲裁委同区）。

#### 三个实质条件（缺一不可）
1. 请求具有**财产给付内容**（欠薪、经济补偿、赔偿金 —— 劳动争议天然满足）
2. 存在**转移、隐匿财产的现实风险**（账户异常流出、设备搬迁、公司注销公示、批量变更法定代表人）
3. **提供明确的财产线索** —— ⚠️ **法院不会主动查控**，你必须自己给出：
   - 银行账号 + 开户行（最有效）
   - 房产具体坐落、车牌号、股权所在企业

#### 保全的期限与费用
```
冻结银行存款：最长 1 年
查封不动产：  最长 3 年
保全费：      上限 5000 元（可主张由败诉方承担）
担保：        可买保全责任险（费用低），或申请免担保
```

#### ⚠️ 风险提示
- 保全只是**临时锁财**，不是实体胜诉
- **保全错误须赔偿**被申请人损失 → 出手前权衡：欠付金额、保全成本、线索把握度
- 优先在"**立案同步交保全**"这个时间窗出招

> 依据：广东高院、省劳动仲裁委指导意见（劳动者凭《受理通知书》即可申请）；
> 民事诉讼法第 103~106 条；仲裁法第 28 条。

### 6.0-bis 被执行人是【上市公司】时的额外压力通道

**先说结论**：证监会**不直接管劳动争议**，银监会**已不存在**。但上市公司有一个**真正管用的软肋 —— 信息披露**。

#### ① 信息披露（最有效的切入点）

沪深交易所《股票上市规则》7.4.1 条规定，上市公司发生的诉讼、仲裁事项**应当及时披露**的情形：

```
(一) 涉案金额超过 1,000 万元，且占最近一期经审计净资产绝对值 10% 以上；
(二) 涉及股东大会、董事会决议被申请撤销或宣告无效的诉讼；
(三) 证券纠纷代表人诉讼。

未达到前款标准或者没有具体涉案金额的诉讼、仲裁事项，
【可能对公司股票及其衍生品种交易价格产生较大影响的，公司也应当及时披露】。
```

**关键在最后那句兜底条款** —— 它不看金额，看**影响**。

而且规则明确要求：应当及时披露重大诉讼仲裁的**重大进展情况，包括仲裁裁决结果以及判决、裁决执行情况**。

**真实案例（证明这条路有效）**
- **东方日升**：5.1 亿元仲裁事项未及时信披 → 收到**深交所监管函**。公司辩称"对披露标准理解不充分、不存在主观故意"，仍被认定违规
- **卓朗科技**：涉诉讼信披不及时 → 被**上交所监管警示**

#### ② 单个人 vs 集体：差别巨大

| 情形 | 能否触发披露 | 打法 |
|---|---|---|
| 单个员工的劳动仲裁 | 金额通常**远达不到** 1000 万 + 10% 净资产 | 基本指望不上 |
| **集体争议**（数十人同时仲裁） | 连续 12 个月**累计计算**；且"批量裁员引发群体性纠纷"可能触发兜底条款 | ⭐ 联合其他被退项的同事，**同步仲裁 + 同步举报信披违规** |

> **所以散户的正确姿势**：不是单独去举报，而是**找到同批被退项的同事一起动**。
> 一旦形成几十人的群体性争议，公司面临的就不只是赔偿金，还有披露义务和股价压力。

#### ③ 投诉渠道（若确需施压）

| 机构 | 管什么 | 渠道 |
|---|---|---|
| **证监会及派出机构（证监局）** | 上市公司信息披露违规、公司治理 | **12386**（证监会投资者服务热线）、证监局信访、交易所举报邮箱 |
| **上交所 / 深交所 / 北交所** | 上市规则执行、纪律处分 | 官网举报、"互动易"/"e 互动"提问（公开可见，公司必须答复） |
| **国家金融监督管理总局**（原银监会+保监会，2023 年改革） | **只监管银行、保险等金融机构**的业务合规 | 12378。⚠️ 若欠薪公司不是金融机构，**完全不归它管** |

#### ④ 一条更朴素但更有效的路

对上市公司而言，**比证监会更怕的是"公开"**：
- 交易所互动平台的**公开提问**（公司必须公开答复）
- 媒体、行业社群的曝光
- 在**年报/半年报**的"重大诉讼"章节里留痕

> **提醒**：上市公司通常法务完备、不会硬扛生效判决，
> 对它们真正有效的不是"找监管"，而是**扎实的保全 + 快速的执行**。
> 信息披露只是辅助筹码，别把主攻方向搞反了。

### 起诉
- 非终局裁决：收到裁决书 **15 日内**起诉
- 终局裁决：**劳动者**不服可向基层法院起诉；**用人单位**只能向中院申请撤销（事由极窄）

### 支付令（最快，适合金额无争议的工资）
```
条件：请求给付金钱/有价证券；到期；与债务人无其他债务纠纷；能送达
流程：向法院申请 → 5 日内发出 → 债务人 15 日内清偿或提出书面异议
      → 不异议不履行 → 直接申请强制执行（支付令本身即执行依据）
注意：债务人一旦提出异议，支付令失效，转入诉讼
```

### 强制执行

**先等履行期届满** —— 裁决书/判决书会载明履行期限（常见为生效后 15 日内或指定日期）。
**期限届满未付，才能申请强制执行。** 这就是你问的"次月发放"那个节点：
不是看公司下个月发不发薪，而是看**裁决书载明的履行期限**到没到。

- 生效文书履行期届满后 **2 年内**申请
- 法院查控：银行、不动产、车辆、股权、公积金、保险
- 措施：冻结划拨、查封拍卖、**限制高消费、列入失信被执行人名单**
- 公司没钱？→ 查**股东抽逃出资、一人公司股东连带、未实缴出资加速到期**（C9）

## §7 时间成本表（给用户一个真实预期）

| 路径 | 最快 | 常见 | 备注 |
|---|---|---|---|
| 监察/稽核施压后和解 | **7~15 天** | 1 个月 | 中小公司最常见 |
| 仲裁调解（开庭前） | 20~45 天 | 1~2 个月 | 黄金窗口 |
| 仲裁一裁终局 | 45~60 天 | 2 个月 | 公司不能起诉 |
| 仲裁裁决（非终局） | 45~60 天 | 2~3 个月 | 公司可能起诉 |
| 一审 | 3~6 个月 | 4 个月 | 简易程序更快 |
| 二审 | +3 个月 | +3 个月 | — |
| 强制执行 | — | 6 个月内 | 有财产即可 |

**总体**：事实清楚、证据齐全、双线施压 → **多数 1~3 个月拿到钱**；公司死磕 → 6~12 个月。

### 三个能再砍一半时间的"快车道"

| 通道 | 怎么用 | 效果 |
|---|---|---|
| **速裁庭** | 立案时在申请书上注明"**申请适用速裁程序**"（多地仲裁委设有劳动争议速裁庭） | 案情简单、标的额小的案件，立案到裁决 **15~30 天** |
| **国务院客户端小程序** | 微信/支付宝搜 → "全国根治欠薪线索反映平台"在线提交 | 直达属地人社，会转派限期答复，比跑窗口快 |
| **小额诉讼程序** | 追索劳动报酬金额明确、标的额小的，起诉时可适用 | **一审终审**，省掉二审 3 个月 |

### ⚠️ 关于"多久拿到钱"的诚实预期

- **赔偿金（N/2N）**：靠仲裁 + 调解，多数 1~3 个月。这是"快钱"
- **社保补缴**：行政途径，公司拖就慢，但滞纳金一直在滚，公司有动力尽快结
- **公积金追缴**：顺利 1~3 个月，**公司硬扛可能 8~12 个月**（见 §3 官方时间线）
  → **不要把公积金当成"快速拿结果"的指望**，它的价值在于：①金额往往最大；②它是**逼公司回到谈判桌的最强筹码**（公司知道一旦责令生效，还得搭上滞纳金和信用记录）

**所以"快速拿结果"的正确打法**：用公积金和社保做**压力**（同步提交、不可逆），用赔偿金做**现金**（谈判落袋）。两条腿，别指望一条腿跑完。

## §8 按情形选路线（决策表）

| 你的情形 | 推荐组合 | 首选目标 |
|---|---|---|
| 刚收到退项通知，还没解除 | 书面异议 + 全面取证 + 按兵不动 | 等公司出招，别自己辞职 |
| 已待岗，生活费发得很低 | 书面异议 → 催告 → 监察 + 仲裁（工资差额） | 先补工资，再谈解除 |
| 已被解除，只给 N | 仲裁主张 2N + 监察 + 社保/公积金投诉 | 2N |
| 已被解除，一分不给 | 监察 + 仲裁（2N + 工资 + 年假 + 加班）+ 公积金投诉 | 2N + 补缴 |
| 被单方降薪，还想拿 N | 书面异议 → 催告 → **被迫解除通知书** → 仲裁 | N + 工资差额（基数按降薪前） |
| 换签过主体，工龄被切 | 仲裁第 1 项请求**确认全程劳动关系** | 工龄合并 → N 翻倍 |
| 外包公司可能跑路/已注销 | 立案 + **财产保全** + 查股东连带 | 保全优先 |
| 只想快速拿钱，金额不大 | 监察投诉 + 支付令 / 一裁终局 | 快 |
| 金额巨大（>30 万） | 直接请律师 + 财产保全 | 别省律师费 |
