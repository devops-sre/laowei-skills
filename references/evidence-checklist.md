# 证据清单与取证 SOP

> **核心原则**：证据的价值 = 证明力 × 能否取得。**优先拿"公司自己生成、自己申报"的东西**（个税、社保、工资流水、系统日志）—— 它们几乎无法抵赖。

---

## 〇、收到通知【之前】的取证 —— 黄金窗口（最重要的一节）

> **为什么必须在通知之前动手**
> 通知一送达，通常 24 小时内发生：工牌失效、账号封禁、被移出群、禁止进入办公区、要求立刻交接。
> 更关键的是，公司从这一刻开始会**主动制造证据**（调监控、发警告信、要求签到打卡、安排"培训"），
> 同时你的每一次激动反应都可能被录下来。
> **通知前你拥有全部权限、全部时间、且完全从容。这个窗口通常只有几天到几周。**

### 0.1 风声信号：看到这些就该开始了

| 信号 | 含义 |
|---|---|
| 甲方削减人头（headcount）、项目预算不再续签 | 外包公司很快启动退项 |
| 被要求交接工作、写操作文档、带新人 | 已在准备替换你 |
| 汇报线变更、组织架构调整、被移出关键项目群 | 岗位即将被动 |
| HR 突然约谈、"聊聊你的发展" | 谈判前奏，全程录音 |
| 同批同事陆续"被优化"、有人在打听赔偿 | 批量清退已启动 |
| 公司开始清理账号权限、统计加班、重签文件 | 动作为解除做准备 |
| 被通知"换个主体签合同""转签一下" | 工龄切割，见 D1 |

### 0.2 T0 —— 今天就必须做完（不依赖任何公司系统权限）

**这一梯队的共同点：数据由第三方机构生成，公司无法篡改、无法否认，且你可以在手机上独立完成。**

| # | 材料 | 去哪拿 | 证明什么 |
|---|---|---|---|
| 1 | **个人所得税「收入纳税明细」** | 个人所得税 App → 办&查 → 收入纳税明细查询 → **按年度逐一导出** | ⭐ 最强证据。公司自己申报的工资数，是**社保/公积金基数差**和**真实工资基数**的铁证 |
| 2 | **银行工资流水** | 银行 App → 导出 PDF（带电子章） | 工资标准、发放主体（若由甲方或关联公司代发 → 证混同用工）、欠发月份 |
| 3 | **社保缴费明细** | 掌上 12333 / 支付宝市民中心 / 微信城市服务 | 缴费基数是否等于实际工资、是否断缴 |
| 4 | **住房公积金缴存明细** | 当地公积金 App / 官网 | 缴存基数与比例；**未开户缴存的要截图"查无记录"** |
| 5 | **劳动合同全部版本** | 自己手里的原件；找不到的立刻拍照归档 | 劳动关系、签约主体、薪资约定；**换签过的每一份都要留** |
| 6 | Offer / 录用通知 / 薪酬确认书 | 个人邮箱 | 薪资结构、年终奖/十三薪约定 |
| 7 | **企业工商信息** | 国家企业信用信息公示系统 / 企查查导出 PDF | 股东、法定代表人、高管重叠 → **证明关联公司/混同用工** |

> **T0 的价值**：即使你明天就被封号，这 7 项已经足够证明劳动关系、工资基数和社保公积金差额 —— 这是整个案子的地基。

### 0.3 T1 —— 本周内完成（需要系统权限，趁权限还在）

| # | 材料 | 怎么做 | 证明什么 |
|---|---|---|---|
| 8 | 近 12 个月**工资条 / 薪资系统** | 手机**录屏**（从桌面开始录 → 登录 → 逐月点开） | 计算基数（含奖金、补贴、提成，往往高于"到手工资"） |
| 9 | **考勤 / 打卡记录** | 打卡 App 导出 + 录屏；门禁记录拍照 | 加班费；待岗期间是否要求出勤 |
| 10 | **绩效评分 / 考核记录 / 晋升评优** | 系统截图或导出 | 反驳"不胜任""绩效不合格"；证甲方实际考核 |
| 11 | **汇报关系与组织架构** | 企业微信/钉钉组织架构截图、日报周报的接收人 | ⭐ 证明**甲方实际用工管理**（推翻"你不是我们员工"） |
| 12 | 工作痕迹：工单、文档、会议记录、发版计划 | 导出与自己相关的部分 | 加班事实的时间锚点 |
| 13 | **工牌、工位、座席图、邮箱后缀、名片** | 拍照 | 组织从属性；工牌 LOGO 是谁的 |
| 14 | **员工手册 / 规章制度** | 内网下载或拍照 | 日后公司援引制度时，你手上有原文可对照（它说"严重违纪"，你看制度写的是不是"一般违纪"） |
| 15 | 关键沟通记录 | 与主管/HR 的微信、邮件、**导出聊天记录**（别只截图） | 安排加班、转签、退项、降薪的原始对话 |
| 16 | 加班审批、出差报销、请假记录 | 系统导出 | 加班与出勤情况 |

### 0.4 T2 —— 有余力再补

- 同事的**私人**联系方式（日后证人）—— 只存私人手机号/微信，**不要在群里讨论维权**
- 往年奖金、十三薪的发放记录（证明年终奖存在且是常态）
- 项目的排期表、发版计划（证明工作强度与加班必要性）
- 公司同期仍在招聘、正常经营的截图（**日后反驳"停工停产""经营困难"**）

### 0.5 存储三原则

```
1. 录屏 > 截图            —— 截图易被质疑篡改，录屏能展示操作路径
2. 两处备份               —— 本地 + 个人网盘/个人邮箱
   ⚠️ 绝不要存在公司邮箱、公司网盘、公司电脑 —— 离职时会被要求归还并清空
3. 保留原始载体           —— 手机/电脑里的原始记录不要删，当庭出示才有效
```

### 0.6 ⚠️ 合规红线（不要因为取证把自己送进去）

| ✅ 可以做 | ❌ 绝对不要做 |
|---|---|
| 复制**自己的**人事数据：工资、考勤、绩效、社保 | **批量下载源代码、客户名单、商业计划** → 可能构成侵犯商业秘密，严重的刑事责任 |
| 导出与自己工作相关的工单、文档、会议记录 | 用他人账号登录、破解系统、绕过权限 |
| 工作会议、HR 谈话的录音（一方录制） | 在更衣室、卫生间等隐私区域偷拍偷录 |
| 依据《个人信息保护法》第 45 条**书面要求公司提供**你的个人信息副本 | 伪造、剪辑、篡改证据 → 一经发现，全案证据可信度崩塌 |
| 拍自己的工位、工牌 | 把公司数据发给无关第三方或发到网上 |

> **法律依据**：《中华人民共和国个人信息保护法》第 45 条 —— 个人有权向个人信息处理者**查阅、复制**其个人信息，处理者应当及时提供。
> 这意味着你可以**书面要求公司提供你的考勤、工资、绩效记录**。这是一步好棋：发函留痕后，公司拒不提供 → 仲裁时承担不利后果（调解仲裁法第 6 条）。

### 0.7 一个提前布局的动作：书面行使"个人信息查阅复制权"

在还没撕破脸时发出这样一封邮件/函件，成本极低、收益极高：

```
主题：关于查阅、复制本人个人信息的申请

本人【姓名】，身份证号【】，在职期间【】。
现依据《中华人民共和国个人信息保护法》第四十五条，申请查阅并复制本人的
下列个人信息，请于十五个工作日内以电子版形式提供：
1. 20XX 年 X 月至今的全部考勤记录（含加班、请假、出差）；
2. 20XX 年 X 月至今的工资明细及构成（含奖金、补贴、提成、加班费）；
3. 历年绩效考核记录与评分依据；
4. 社会保险及住房公积金的申报基数记录；
5. 本人的岗位职责、汇报关系及项目安排记录。

请书面回复。
```

**为什么值得做**：①合法，公司无法以"泄密"为由追责；②留下书面痕迹，证明你早已主张权利；③公司一旦拒绝或敷衍，日后仲裁中就是它"掌握证据而不提供"的直接证据。

## 一、证据分级

| 级别 | 说明 | 例子 |
|---|---|---|
| **A 级（铁证）** | 公司或第三方机构官方生成，公司无法否认 | 个税 App 收入纳税明细、社保/公积金缴费明细、银行代发工资流水、劳动合同、公司盖章的解除通知书 |
| **B 级（强证）** | 系统记录，需佐证但未篡改即可采信 | 考勤打卡记录、企业微信/钉钉聊天与审批、绩效评分、工牌、座席图、门禁记录 |
| **C 级（辅助）** | 需要与其他证据形成链条 | 同事证言、自行制作的统计表、录音、照片 |
| **D 级（慎用）** | 单独使用常被否 | 单方制作的邮件截屏、自行整理的加班统计表（见 C18 反面案例） |

> **组合规则**：D + B + A 形成闭环才稳。加班事实尤其如此。

## 二、按用途的分类清单（可直接打勾使用）

### ① 证明劳动关系 & 工龄（决定"告谁"和"N 是多少"）
- [ ] 劳动合同（**全部版本**，含历次换签的每一份）
- [ ] 入职登记表 / Offer / 录用通知邮件
- [ ] 离职证明 / 解除（终止）劳动关系通知书
- [ ] 社保缴费明细（人社 App，截图 + 导出 PDF）
- [ ] 公积金缴存明细
- [ ] 个税 App「收入纳税明细查询」（**按年度导出**，可证每一个月的申报工资和实际任职单位）
- [ ] 银行工资流水（PDF 版，能看到**付款方名称** → 证交叉发薪）
- [ ] 工牌 / 工位照 / 名片 / 邮箱后缀 / 企业微信组织架构
- [ ] 换签主体的沟通记录（"公司安排你转签"的微信/邮件）
- [ ] 关联关系证据：企查查/天眼查导出的**股东、法定代表人、高管重叠**工商档案

### ② 证明算钱基数
- [ ] 近 12 个月工资条 / 薪资系统截图（**录屏**）
- [ ] 薪酬确认书 / 调薪通知 / Offer 中的薪资结构
- [ ] 年终奖发放记录、十三薪约定
- [ ] 补贴、绩效、提成的发放规则与历史记录
- [ ] 个税申报工资（用作**交叉验证**，常高于工资条上的"基本工资"）

### ③ 证明甲方实际用工（推翻"你不是我们员工"）
- [ ] 日报 / 周报（发给甲方主管的）
- [ ] 绩效评分表、考核邮件、晋升/评优通知（署名甲方）
- [ ] 甲方主管的工作指令（企业微信/钉钉/邮件）
- [ ] 甲方系统的账号、权限、操作日志
- [ ] 项目排期、发版计划、工单系统记录
- [ ] 甲方办公场所的门禁、工位照片
- [ ] 请假/加班审批流程的审批人（显示是甲方的人）

### ④ 证明退项待岗
- [ ] 《退项通知》/《待岗通知》/《培训通知》**原文**（截图 + 原件）
- [ ] 待岗期间的打卡要求与打卡记录（**证明你仍在提供劳动/随时待命**）
- [ ] 待岗期间的工资发放记录（证明降到了多少）
- [ ] 与 HR 沟通待岗期限、待遇的聊天/录音
- [ ] 公司同期仍在招聘、经营正常的证据（**反驳"停工停产"**）
- [ ] 公司规章制度中关于待岗的条款（要求公司举证）

### ⑤ 证明解除（决定 N / N+1 / 2N）
- [ ] 解除通知书的**原文与送达方式**
- [ ] 违纪处罚单、警告信、监控回放说明
- [ ] 员工手册、规章制度（**要求公司证明已公示、经民主程序**）
- [ ] 协商过程的录音、聊天记录
- [ ] 是否提前 30 天书面通知的证据
- [ ] 是否通知工会的证据（**要求公司举证**）
- [ ] 经济性裁员：向劳动行政部门报告的回执、向全体职工说明的通知（**要求公司举证**）

### ⑥ 证明加班（互联网重灾区）
- [ ] 打卡记录 / 门禁记录 / VPN 与堡垒机登录日志（**录屏导出**）
- [ ] 代码提交记录（Git log）、工单操作记录、文档编辑时间
- [ ] 企业微信/钉钉/飞书的**非工作时间**消息记录（导出聊天记录）
- [ ] 会议邀请、会议纪要（含时间）
- [ ] 领导在群里 @ 你安排工作的记录
- [ ] 发版/上线/故障处理记录（深夜、周末）
- [ ] 加班申请与审批记录（如有）
- [ ] 出差记录、差旅报销（含日期）

### ⑦ 证明社保 / 公积金差额
- [ ] 社保缴费基数明细（人社 App）
- [ ] 公积金缴存基数与比例明细（公积金 App）
- [ ] 个税申报工资（**证明真实工资 vs 缴费基数的差额**）
- [ ] 银行流水（证明实际发放金额）

- [ ] 书面异议函及 EMS 单号、签收记录
- [ ] 催告函及 EMS 单号、签收记录
- [ ] 被迫解除通知书及送达证据（钉钉已读 + EMS 签收，见 C11）
- [ ] 与 HR / 主管的微信、邮件、通话录音
- [ ] 谈判过程记录（用于证明公司承认过某些事实）

## 三、取证方法（决定证据能不能被采信）

### 录屏 > 截图
**截图易被质疑篡改，录屏能展示操作路径**。手机自带录屏即可，操作时：
1. 从**手机桌面**开始录 → 打开 App → 登录 → 进入页面 → 逐项点开
2. 录完立刻**导出并备份到两处**（本地 + 云盘/邮箱）
3. 关键页面录完再补一张截图备用

### 电子数据的公证 / 存证
- 涉及金额大、公司可能抵赖的（如关键聊天记录）：使用**时间戳/区块链存证**（各地公证处在线公证平台、权利卫士、公证云等）
- 简单场景：**录屏 + 原始载体（手机）当庭出示**通常已足够

### 录音的合法性边界
- ✅ 可用：工作会议、HR 谈话、公共办公区的对话（一方录制、内容涉及对方、未侵害合法权益）
- ❌ 禁用：侵入他人住宅、窃听设备、窃取账号密码取得的材料
- 做法：手机正常录音，保存**原始文件**（不要剪辑），导出备份

### EMS 邮寄（送达的黄金手段）
```
1. 一式两份，自己留一份
2. 快递封面【手写】文件全称，如"《要求补缴社会保险及住房公积金催告函》"
3. 寄送地址：公司【注册地】（工商登记地址）+ 实际经营地各寄一份
4. 保留：快递单原件 + 官网签收截图 + 内件照片
5. 同步：邮件 + 企业微信/钉钉发送，截图保存"已读"
```
> 三方送达（EMS + 邮件 + 企业微信）是为了防止公司抗辩"没收到"。

### 已经离职 / 权限被关怎么办
| 材料 | 替代方案 |
|---|---|
| 企业微信/钉钉记录 | 提前导出；已关权限的可申请**仲裁委调查取证**或要求公司提供 |
| 考勤记录 | 主张**由公司掌握**，不提供则承担不利后果（调解仲裁法第 6 条、司法解释一第 42 条） |
| 代码提交记录 | GitHub/GitLab 个人账号的 contribution 记录；个人邮箱中的 commit 通知 |
| 工资条 | 银行流水 + 个税 App 双向还原 |
| 同事证言 | 请前同事出具书面证言并附身份证复印件，注明"愿意出庭作证" |

## 四、取证时间轴

### 阶段 0：还在职、风声已起（**黄金期**）
- 立刻导出：个税明细、社保/公积金明细、银行流水
- 逐月录屏：工资条、考勤、绩效
- 备份：项目相关的工作痕迹（工单、代码、文档、邮件）
- 保存：组织架构、汇报关系截图

### 阶段 1：收到退项/待岗通知当天
- 保存通知原文（**别急着回复**）
- 24 小时内发出《书面异议函》（模板 §1）
- 开始记录待岗期间的**每一天**：是否要求打卡、是否安排工作、发了什么通知

### 阶段 2：收到降薪/解除通知
- 保存通知原件，拍照 + 扫描
- **不要签任何文件**（尤其是"自愿离职""协商一致""放弃权利"）
- 被迫解除的：按模板 §3 送达《被迫解除劳动合同通知书》

### 阶段 3：离职后
- 索要**离职证明**（公司不出具可主张第 89 条损害赔偿）
- 确认社保、公积金的**停缴月份**
- 核对最后一笔工资、年假折算、奖金是否结清
- **1 年内**提起仲裁

## 五、组织证据的标准格式（提交仲裁用）

```
证据目录
```

## 六、四个高频翻车点

1. **只有截图没有录屏** → 公司一句"真实性不认可"就可能不被采信
2. **只提交打卡记录主张加班** → 被认定"只能证明两个时间点"（C18）→ 必须补工作产出证据
3. **没保留 EMS 单号** → 被迫解除的送达时间无法证明 → 整个主张可能不成立
4. **签了"自愿离职"才来找证据** → 举证责任反转，几乎无法翻盘 → **任何时候先别签字**
