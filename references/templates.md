# 文书模板（可直接套用）

> **通用填写规则**
> - `【】` 内为待填内容，填完删除括号
> - 所有文书**一式两份**，自己留一份
> - 发出方式**三件套**：EMS（封面手写文件名）+ 公司邮箱 + 企业微信/钉钉，全部截图留存
> - 日期一律用中文大写或 `20XX 年 X 月 X 日`，避免歧义

## §0 已经签了"自愿离职/放弃权利"怎么办

**先判断签的是什么**

| 签的文件 | 后果 | 补救 |
|---|---|---|
| 《离职申请》写"个人原因" | 经济补偿主张基本丧失 | 收集签署时的**受胁迫/重大误解/显失公平**证据：待岗期间签署、未告知后果、公司承诺补偿后反悔的聊天记录。可主张撤销 |
| 《协商一致解除协议》约定了补偿金 | 有效，按协议履行 | 若公司**未按协议付款** → 直接申请仲裁/支付令要求履行，不必再争性质 |
| 《放弃权利承诺书》 | 放弃部分一般有效，但**违反法律强制性规定**的部分（如放弃社保、公积金）无效 | 社保公积金**照样可以走行政投诉** |
| 《解除通知书》上签字（签收） | **签收 ≠ 认可** | 在签字处注明"**仅表示收到，不认可解除理由**"，或另发书面异议 |

**补救动作（立刻）**
1. 发一份《声明函》：说明签署背景、不认可解除理由、保留全部法定权利
2. 若公司承诺过补偿但没写进协议 → 找出聊天/录音证据，主张协议内容与真实意思不符
3. 社保、公积金**不受协议影响**，立刻启动行政投诉（这两块是"放弃权利"也挡不住的）

## §1 书面异议函（收到退项/待岗/降薪通知后 24 小时内发）

```
【异议函】

【公司名称】：

本人【姓名】，身份证号【】，于【入职日期】与贵司签订劳动合同，
现岗位为【岗位】，劳动合同期限至【日期】。

本人于【日期】收到贵司发出的《【通知名称】》，内容为【简述：退出项目/进入待岗/调整薪酬】。

对此，本人明确表示【不同意】，理由如下：

一、本人与贵司的劳动合同合法有效，约定的工作岗位为【】，工作地点为【】，
    薪酬标准为【】。贵司在未经双方协商一致的情况下，单方变更本人的
    工作岗位/工作地点/薪酬标准，违反了《中华人民共和国劳动合同法》
    第三十五条"用人单位与劳动者协商一致，可以变更劳动合同约定的内容。
    变更劳动合同，应当采用书面形式"的规定。

    所称"劳动合同订立时所依据的客观情况发生重大变化"，本人所在岗位
    及贵司经营状况并未发生致使劳动合同无法履行的情形。

三、即使确需安排停工停产，依据《工资支付暂行规定》第十二条，第一个工资
    支付周期内应按劳动合同约定标准支付全额工资；超过一个工资支付周期的，
    本人如提供了正常劳动，报酬不得低于当地最低工资标准。

据此，本人正式提出如下要求：

1. 自本函送达之日起，请贵司按劳动合同约定恢复本人的原工作岗位、工作地点
   及薪酬标准，并足额安排工作任务；
2. 补发自【日期】起的工资差额共计人民币【】元；
3. 继续依法为本人足额缴纳社会保险费及住房公积金。

请贵司于收到本函之日起【五】个工作日内书面答复。在贵司依法纠正前，
本人保留依法主张全部权利（包括但不限于要求补发工资、支付经济补偿金
或违法解除赔偿金、向劳动保障监察部门、社会保险费征收机构及住房公积金
管理中心投诉举报）的权利。

特此函告。

                                            声明人：【签名】
                                            20XX 年 X 月 X 日

附件：1. 劳动合同复印件
      2. 《【通知名称】》复印件
      3. 近 12 个月工资发放记录
```

> ⚠️ **这一步是整个维权链条的地基**。没有书面异议，后面"被迫解除"很可能不成立。

## §1.1 【退项场景专属】异议函 —— 收到《退项通知》后 24 小时内发

> **为什么退项必须单独发一份异议函**
> "退项"是外包公司最常用、也最容易让人放松警惕的开场白。它本身不是解除，但它是
> 后续"待岗 → 培训 → 找茬警告 → 违纪解除"这条链路的**起点**。
> 公司真正的目的，是让你在不知不觉中**接受劳动条件的变更**（换地点、换内容、降待遇），
> 或者让你自己走人。
> **异议函的唯一作用**：在第一时间把"我从未同意"这件事钉死，**堵住公司日后说"员工已同意/默认"**。
> 这一步不做，后面"被迫解除拿 N"很可能整个不成立。

### 发给谁（比内容更重要）

| 对象 | 方式 | 目的 |
|---|---|---|
| **公司法定代表人 / 总经理** | **EMS 寄公司【注册地址】（工商登记地址）**，收件人写"法定代表人 XXX 收" | ⭐ 构成对公司的**法律有效送达**，日后无法抗辩"没收到" |
| HR 负责人 / 你的 HRBP | 公司邮箱 + 企业微信 | 让实际经办人知情，形成证据链 |
| 直属上级 / 项目负责人 | 企业微信 + 个人邮箱 | 证明具体管理方知情 |
| 你自己 | 留一份原件 + 内件照片 | 归档 |

> ⚠️ **只发微信、只发邮件都不够**。EMS 到注册地址 + 法定代表人收，是唯一能拿出
> **签收回执**的方式。快递封面必须**手写**文件全称。

### 时间
```
收到《退项通知》当天 → 最迟下一个工作日
超过 3 天不发，公司就会开始主张"你已默认同意"
```

## §1.2 报到声明 —— 去新地点报到/参加培训时，当天当场递交

> **这一步是退项场景最容易踩的坑**
> - **不去** → 公司按"旷工"处理，依第 39 条解除，**一分钱没有**
> - **去了但什么都不说** → 公司日后主张"员工已实际履行变更后的安排，视为同意"
>
> **正确做法：人必须去，但当场递交书面声明。** 这样既不构成旷工，又保留了全部异议。
> （上海宝山案的小陈就是去了培训地点，然后被监控盯了 3 个月 —— 但她赢在每一步都有记录。）

```
报到声明

【公司全称】：

本人【姓名】于今日（20XX 年 X 月 X 日 X 时）按贵司《【通知名称】》
的要求，前往【        】报到/参加培训。

本人特此声明：

1. 本人今日报到系服从贵司管理安排，【不代表本人同意】变更劳动合同
   约定的工作岗位、工作地点、工作内容及薪酬待遇；本人已于
   20XX 年 X 月 X 日发出《关于〈退项通知〉的异议函》，该异议继续有效。
2. 截至本声明作出时，贵司【未向本人安排任何具体工作任务 /

请签收人签字确认收到本声明（签收仅表示收到，不代表认可其内容）。

> **"公司让我待岗，却拿不出停工停产的证据；我全程服从安排，却被降薪"**。

**配套动作**
- 每天下班前用**个人邮箱**给自己发一封当天的记录（邮件时间戳 = 不可篡改的时间证明）
- 每收到一份公司通知，24 小时内回一份书面回应
- 全程**不签**任何文件、**不主动**提交离职申请、**不缺席**任何要求出席的场合

## §3 被迫解除劳动合同通知书（走 38 条拿 N，慎用但极有效）

> **使用前提（必须同时满足）**：
> ① 已发出书面异议并留痕；② 公司确实存在欠薪/未依法缴社保/未提供劳动条件等法定情形；③ **你确定不要求继续履行**
> **送达即解除**：自公司签收之日起劳动关系解除。**签收证据是命根子**。

```
【被迫解除劳动合同通知书】

【公司名称】：

本人【姓名】，身份证号【】，于【日期】与贵司建立劳动关系，
岗位【】。现本人依据《中华人民共和国劳动合同法》第三十八条第一款
之规定，被迫提出解除与贵司的劳动合同，理由如下：

一、贵司【未及时足额支付劳动报酬】。
    自【日期】起，贵司在未与本人协商一致、亦无法律依据的情况下，
    将本人月工资由【】元降至【】元（/ 拖欠【】年【】月至【】月工资），
    已构成《劳动合同法》第三十八条第一款第（二）项"未及时足额支付
    劳动报酬"的情形。本人已于【日期】发出《异议函》明确提出异议，
    贵司至今未予纠正。

二、贵司【未依法为本人缴纳社会保险费 / 未按本人实际工资足额缴纳
    社会保险费】，构成第三十八条第一款第（三）项情形。

三、贵司在【待岗/培训】期间未提供约定的劳动条件，未按《工资支付暂行
    规定》第十二条支付相应报酬。

依据《劳动合同法》第三十八条第二款，本人无需事先告知，现通知如下：

1. 本人与贵司的劳动合同自本通知书送达贵司之日起解除；
2. 请贵司于解除之日起【三】日内，一次性结清本人全部工资、
   加班费、未休年休假工资及其他应得款项；
3. 请贵司依据《劳动合同法》第四十六条第一项、第四十七条之规定，
   向本人支付解除劳动合同的经济补偿金：
   工作年限【】年 → 【N】个月 × 月均工资【】元 = 人民币【】元；
4. 请贵司于解除之日起十五日内为本人办理档案和社会保险关系转移手续，
   并依法出具解除劳动合同证明（《劳动合同法》第五十条）；
5. 请贵司依法补缴在职期间的社会保险费及住房公积金。

如贵司逾期未履行上述义务，本人将依法申请劳动仲裁，并保留主张全部
法定权利的权利。

                                            通知人：【签名】
                                            20XX 年 X 月 X 日

## §8 调解协议必写的 8 个条款

签调解书/和解协议前逐条核对：

1. **金额与币种**：大写 + 小写，明确是税前还是税后
2. **付款期限**：具体到日，如"20XX 年 X 月 X 日前一次性支付至申请人指定账户"
3. **收款账户**：开户行、户名、账号
4. **违约条款**："逾期未付的，按全额【2N 金额】元执行"（**最重要**）
5. **离职证明**："被申请人于付款当日出具解除劳动合同证明，注明【非因劳动者原因解除】"
6. **社保公积金**：明确补缴/转移的截止日期；公积金补缴单独约定
7. **年休假/奖金**：已结清的一并写入，避免二次争议
8. **一次性了结条款**：明确"除本协议约定外，双方别无其他争议"，但**社保公积金的行政义务不因本条免除**

> **绝对不写**："申请人因个人原因离职""申请人自愿放弃全部权利""双方确认不存在违法解除"
