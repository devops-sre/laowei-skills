# 阶段 0：谈话前的三个前置判断

**这三个问题必须在任何行动之前搞清楚，它们决定后面所有策略。**

| # | 判断 | 怎么看 | 决定什么 |
|---|---|---|---|
| 0.1 | **合同期限类型** | 翻合同第一行：写"以完成 XX 项目为期限"还是"2021.6–2024.6" | 项目制 → 终止给 **N**；固定期限 → 辞退是 **2N** |
| 0.2 | **工资结构有没有被拆分** | 对比：合同工资 / 银行到账 / 个税申报 / 社保基数，四个数字是否一致 | 决定**真实基数**，往往比合同数字高一倍以上 |
| 0.3 | **告谁** | 谁发工资、谁缴社保、谁管考勤、谁打分 | 外包公司 +（甲方连带？） |

> **0.2 是外包维权的核心战场，单独展开见阶段 2。**

# 阶段 1：HR 找你谈话（退项 / 降薪）—— 当天做什么

## 1.1 谈话中的三个动作

```
① 开录音（手机正常录音即可，保存原始文件不剪辑）
② 不表态、不承诺、不签字
   —— 不说"我考虑一下""那行吧""我理解"
   —— 只说："我听明白了，请给我书面通知，我需要时间看。"
③ 追问三个问题并让对方回答（录音里要有）：
   "这次安排的依据是什么？"
   "我的工资标准会变吗？具体变成多少？"
   "如果我不同意，公司接下来会怎么处理？"
```

**为什么必须追问**：公司最怕留下"单方变更"的证据。它含糊其辞，日后就会说"我们协商过""员工知情"。你把问题问出来，它的回答就是证据。

## 1.2 谈话结束后立刻做（当天内）

1. 把谈话内容**整理成文字**，发到自己**个人邮箱**（时间戳 = 不可篡改的时间证明）
2. 给 HR 发一条**确认微信/邮件**（把口头内容书面化）：
   > "就今天下午的沟通，我确认一下我的理解：公司通知我从 X 月 X 日起退出 XX 项目，之后【待岗/到 XX 报到/月薪调整为 XX 元】。如理解有误请指正。我对此安排**持保留意见**，请以书面形式正式通知。"
3. 对方无论回什么（包括不回），都是证据

> **这条微信的价值**：把"公司单方通知"这件事钉死，且证明你当场就**没同意**。

# 阶段 2：证据收集 —— 工资结构拆分专项 ⭐

## 2.1 为什么这是核心战场

外包公司压低赔偿的**主要手段不是不给，而是把基数做低**：

```
合同写：基本工资 4000 元
社保基数：4000 元
实际每月到账：15000 元

公司说：N = 4000 × 年限
你主张：N = 15000 × 年限        ← 差 3.75 倍
```

**法律结论（2026 年主流裁判规则）**：以"合理避税"为名约定低工资，
同时违反个税征管和社会保险的**强制性规定**，属恶意串通损害国家税收与社保基金利益
→ **该约定无效**，应按劳动者**实际全部到手工资**认定。

## 2.2 四种拆分套路与识别方法

| 套路 | 长什么样 | 识别信号 |
|---|---|---|
| **① 私户/微信走账型** | 公账发基本工资，大头由**法定代表人、财务、老板亲属**的个人卡/微信转给你 | 每月固定日期收到**个人账户**转账，金额固定或呈规律 |
| **② 发票报销抵工资型** | 合同写低工资，其余要你**找发票报销**领取 | 每月有固定"报销款"入账，公司从不真正审核票据 |
| **③ 关联公司/亲属账户代发型** | 由老板母亲名下企业、关联公司同期另发一笔 | 两笔款**同一天**到账，付款方不同 |
| **④ 个体户/服务费型** | 让你注册个体户，公司改付"服务费""咨询费" | 你被要求注册个体户、开票，但**考勤管理一切照旧** |

> ⚠️ **第 ④ 种最危险**：不但社保没了，还可能涉及**虚开发票**（刑法第 205 条），
> 企业负责人和财务可追究刑事责任。遇到这个，**立刻停止配合并保留所有沟通记录**。

## 2.3 每种套路的证据收集方法（对照表）

### 套路 ① 私户 / 微信走账

| 要固定什么 | 怎么拿 | 证明什么 |
|---|---|---|
| **转账流水全量** | 银行 App 导出全部流水 PDF（含付款方姓名/账号）；微信账单导出 | 每月实收总额 |
| **付款方身份** | 企查查查该人是否为公司**法定代表人/股东/财务负责人**；或工商档案 | 证明是公司发薪，不是私人借款 |
| **同期性与规律性** | 把所有到账记录做成**一张月度表**，标注日期、金额、付款方 | 固定日期、固定金额 = 工资性质 |
| **公司索要账号的记录** | 法人/财务向你索要银行卡号的微信、短信 | ⭐ 海淀法院案例的关键证据 |
| **个税申报数** | 个税 App 收入纳税明细 | 公司申报的 vs 实际发的，差额一目了然 |

### 套路 ② 发票报销抵工资
- 每月报销**审批记录**（OA/钉钉截图或录屏）
- 报销款**到账流水**（证明金额固定、按月发放）
- **公司从未要求提供真实票据**的证明（聊天记录里让你"随便找点发票"）
- ⭐ 关键论点：公司**无法证明**报销的业务真实性、无法提供租房合同/票据 → 承担不利后果

### 套路 ③ 关联公司 / 亲属账户代发
- 两家公司的**工商注册信息**（企查查导出）
- **法定代表人/股东之间的亲属关系**（法院可依职权调取工商档案中的身份证信息）
- 两笔款的**同期性**证明（银行明细对比）
- 法人向你索要银行账户的**短信/微信**

### 套路 ④ 个体户 / 服务费（立刻停止配合）
- 公司要求你注册个体户的**书面通知/聊天记录**
- 你**仍在接受考勤、规章制度管理**的全部证据（打卡、日报、请假审批）
- 服务费流水

## 2.4 证据链组装：把"实际工资 = X"钉死

**单一证据会被打掉，四种证据交叉才能成立：**

```
┌─────────────────────────────────────────────────┐
│  ① 银行流水（实收总额）                            │
│  ② 个税申报（公司自己报的数）  ← 反证力最强        │
│  ③ 工资条/薪资系统（结构说明）                     │
│  ④ 聊天记录（公司承认"月薪 X 万"）                 │
│         ↓ 四者互相印证                             │
│  结论：本人月均应得工资 = X 元                      │
└─────────────────────────────────────────────────┘
```

**组装成一张表**（提交仲裁时最有力）：

| 月份 | 公账到账 | 私户到账 | 报销款 | 合计实收 | 个税申报 | 社保基数 |
|---|---|---|---|---|---|---|
| 2025-01 | 4,000 | 11,000 | 0 | 15,000 | 4,000 | 4,000 |
| 2025-02 | 4,000 | 11,000 | 2,000 | 17,000 | 4,000 | 4,000 |
| … | | | | | | |
| **月均** | | | | **15,800** | **4,000** | **4,000** |

> 这张表一摆出来，**社保基数差、公积金基数差、赔偿基数差**三笔账同时成立。

## 2.5 ⚠️ 你自己的风险（必须说清楚）

如果你**主动配合**公司拆分工资（提供亲属账户、代签劳务协议、找发票冲账），会有三重代价：

1. **工资标准举证困难** —— 败诉风险实打实
2. **贷款/信用卡审核受影响** —— 银行看你"官方工资"很低
3. **个人诚信不良记录** —— 税务机关追缴时，你可能被要求**补税 + 滞纳金**

> **所以**：现在还在配合的，**从今天开始留证据**（尤其是"公司要求我这么做"的聊天记录），
> 证明你是**被动配合**，而非主动合谋。

# 阶段 4：五条线并行递交证据链（第 3~10 天）

> **为什么必须并行**：单线走，公司会拖；五条线同时点着，
> 公司的法务会算一笔账 —— 补缴 + 滞纳金 + 罚款 + 行政记录 > 你的赔偿金，于是主动找你谈。

| 线 | 入口 | 递交什么 | 关键话术/写法 |
|---|---|---|---|
| **① 劳动监察** | 12333 / 12345 / **国务院客户端小程序 → 全国根治欠薪线索反映平台** | 投诉书 + 证据复印件 | ⭐ 请求必须写"责令限期支付，并依**劳动合同法第 85 条加付 50%~100% 赔偿金**" |
| **② 税务 / 社保** | **12366** / 税务局官网"税收违法行为检举"平台 / 12333 社保稽核 | 工资流水 + 个税明细 + 社保基数明细，指出**四者不一致** | "公司未按实际工资申报社保缴费基数，涉嫌拆分工资、体外发薪" |
| **③ 公积金** | 12329 / **全国住房公积金小程序** / 公司注册地公积金中心 | 缴存明细 + 个税工资明细 | "责令补缴 X 年 X 月至 X 月，基数按 X 元核定" |
| **④ 个税申诉** | **个人所得税 App → 收入纳税明细 → 申诉** | 对不实申报记录发起申诉 | "被任职"或"收入不符"申诉 → 税务机关会向公司核实 |
| **⑤ 劳动仲裁** | 当地仲裁委（免费） | 申请书 + 证据目录 + 证据（一式三份） | 第 1 项请求写**确认劳动关系及连续工龄** |

## 4.1 税务线为什么威力最大

**金税四期已实现四流交叉比对**：个税申报数据、社保缴纳记录、银行流水、企业工资成本。

实务口径：**个税工资与社保基数差异 > 10% 直接触发预警工单**，无需人工抽查。

公司面临的后果：
```
补缴历年社保差额
+ 每日万分之五滞纳金
+ 欠缴额 0.5~3 倍罚款
+ 情节严重的认定偷税（可移送公安）
+ 信用记录
```

> **谈判话术**："我的赔偿金是 8 万。但如果我把工资拆分的流水交给税务，
> 公司要补的社保加滞纳金加罚款可能是 20 万，还要进信用记录。您觉得哪个划算？"

**⚠️ 但要提醒用户**：这条路**不可逆**。一旦举报，公司在税务上就留下了痕迹，
谈判余地会变小。建议**先仲裁立案，把税务举报作为后手牌**，
或至少在第一次调解谈崩后再打出去。

# 阶段 5：各条线的时间线（追缴流程逐步展开）

```
【第 1~3 天】  异议函发出 + 全套证据导出归档
【第 3~7 天】  三条行政线递交（监察 / 税务 / 公积金）+ 个税申诉
【第 5~10 天】 仲裁立案（先立案保住时效，证据可补交）

【第 7~15 天】 监察线通常先见效：
               5 个工作日决定是否立案 → 下达《限期整改指令书》
               → 大量公司在这个节点主动联系你谈

【第 15~45 天】仲裁开庭前调解 ← 黄金收钱窗口
               仲裁委受理后 45 日内裁决（速裁庭 15~30 天）

【同期滚动】   社保/公积金线按自己节奏走：
               公积金：60 日内处理决定 → 单位 60 日复议期 + 6 个月诉讼期
                       → 期满未整改 → 3 个月内申请法院强制执行
                       （顺利 1~3 个月，硬扛 8~12 个月）

【第 45~90 天】裁决生效 / 一审（不服裁决 15 日内起诉）
【+3 个月】    二审
【执行】       生效后 2 年内申请强制执行，法院查控 6 个月内结案
```

**关键提醒**
- 监察线**最快**，但只管欠薪、社保这类事实清楚的；赔偿金争议要仲裁
- 公积金线**最慢但金额最大**，别把它当现金指望，它是压力筹码
- 仲裁**立案要早**，1 年时效不等人

# 阶段 6：仲裁 → 一审 → 二审 → 执行

## 6.1 ⚠️ 关于"跳过仲裁直接诉讼"—— 澄清与真实路径

**先纠正一个流传很广的误解**：劳动争议实行"**一调一裁两审**"，
**仲裁是法定前置程序**，一般情况下**不能跳过仲裁直接一审**。

但确实存在**三个法定例外**，符合条件时可以直接去法院：

| # | 例外情形 | 依据 | 实操要点 |
|---|---|---|---|
| **①** | **持有公司的工资欠条**，且诉讼请求**不涉及劳动关系其他争议** | 司法解释一**第 15 条** | 视为拖欠劳动报酬争议，法院按**普通民事纠纷**受理，无需仲裁前置。欠条不一定要写"欠条"二字，**只要书面文件内容是"公司欠你多少工资"即可** |
| **②** | **仲裁机构逾期未作出受理决定或裁决** | 司法解释一**第 12 条** | 可直接起诉，但须提交仲裁机构出具的**受理通知书**或其他已接受申请的凭证。例外：移送管辖、正在送达、等待另案结果、正在排期开庭、鉴定程序中 |
| **③** | **支付令 / 调解协议不履行** | 司法解释一**第 13 条**；劳动合同法第 30 条第 2 款；调解仲裁法第 16 条 | 申请支付令被裁定终结后，依**调解协议**直接起诉的，法院应予受理 |

**另外一条实用路径**：在**劳动争议调解委员会**主持下，仅就劳动报酬争议达成调解协议，
用人单位不履行给付义务的，劳动者**可直接向法院起诉**，法院按普通民事纠纷受理。

> **所以"跳过仲裁"的真实打法**：
> ① 想办法让公司出具**工资欠条/结算单**（哪怕写"今欠 XX 工资 X 元"）→ 直接起诉
> ② 仲裁立案后若**逾期未裁决** → 凭受理通知书直接起诉
> ③ 走**调解协议 + 司法确认**，对方不履行直接申请执行
>
> **不存在**"在仲裁申请书里写一句话就能跳过仲裁"这种操作。

## 6.2 一审 / 二审

| 阶段 | 时限 | 注意 |
|---|---|---|
| 起诉期 | 收到非终局裁决书 **15 日内** | 过期裁决生效 |
| 一审 | 简易程序 3 个月 / 普通程序 6 个月 | 欠薪案件常适用**小额诉讼程序，一审终审** |
| 上诉期 | 收到判决书 15 日内 | |
| 二审 | 3 个月 | 二审为终审 |
| 执行申请 | 生效后 **2 年内** | 法院查控 6 个月内结案 |

**终局裁决的特殊规则**（司法解释一第 21 条）：
劳动者向基层法院起诉、单位向中院申请撤销的，**中院不予受理**。
—— 也就是说终局裁决下，起诉权在劳动者手里。

## 6.3 执行阶段（真正的"最后一公里"）

```
申请强制执行
  ↓ 法院查控：银行 / 不动产 / 车辆 / 股权 / 公积金 / 保险
  ↓ 冻结划拨 / 查封拍卖
  ↓ 限制高消费 + 列入失信被执行人名单
  ↓ 公司没钱？→ 查股东：
      · 一人公司股东不能证明财产独立 → 连带责任（见 C9）
      · 抽逃出资 / 未实缴出资加速到期
      · 未清算即注销 → 股东、清算义务人担责
```

# 阶段 7：法院判决真实案例逐步拆分

## 案例 A：老板母亲名下公司另发 5000 元 —— 算不算工资？

**来源**：北京市海淀区人民法院（法官蔡笑释法，中新经纬报道）

| 步骤 | 内容 |
|---|---|
| **案情** | 陈先生任 UI 设计总监，公司主张月薪 2 万（有转账记录）。陈先生主张 2.5 万 —— 另有 5000 元由**法定代表人母亲名下的培训中心**同日支付 |
| **争议焦点** | 那 5000 元是不是工资？ |
| **陈先生的证据** | ① 两家公司工商注册信息；② 自己的银行明细；③ **法定代表人索要其银行账户的手机短信** |
| **法院的动作** | 公司全盘否认 → 法院**依职权调取工商档案中袁某、方某的身份证复印件**，追加培训中心为当事人 → 公司才承认母子关系、承认手机号归属 |
| **认定逻辑** | 短信证明法人索要账号 + 工商信息证明母子关系 + **两公司付款具有同期性** → 应由公司作出解释并举证，否则承担不利后果 |
| **结果** | 采信员工主张，**认定月工资 2.5 万元**，判决支付工资差额 |

> ⭐ **可复用**：这条链最关键的是**"同期性"** —— 两笔款同一天到账，公司很难解释成别的。

## 案例 B：工资发到员工父亲账户 —— 算不算工资？

| 步骤 | 内容 |
|---|---|
| **案情** | 马先生主张月薪 1.5 万：7500 到自己账户，7500 到**父亲账户**。后父亲账户部分缩至 4500。公司以未足额支付工资为由解除并索赔 |
| **公司抗辩** | 出示**有父亲名字的劳务协议**，称付给老马的是劳务费，与马先生无关 |
| **法院查明** | ① 老马**已退休多年**、**不在京生活**；② 公司**无法出示老马的入职手续**；③ 劳务协议**实为马先生代签**；④ 公司**无法说明劳务内容** |
| **结果** | 当庭调解，公司一次性支付 2 万余元 |

> ⭐ **可复用**：公司的抗辩越具体，越容易被戳穿。抓住四点：人不在岗、无入职手续、协议代签、说不出劳务内容。

## 案例 C："代发工资 3000 + 报销款 2000" —— 报销款算不算工资？

| 步骤 | 内容 |
|---|---|
| **案情** | 小王月收 3000（代发工资）+ 2000（报销款），主张月薪 5000。公司称 3000 是工资，2000 是"人文关怀"报销房租 |
| **公司三处举证不能** | ① 无法证明双方约定月薪 3000；② 无法证明有报销房租的约定；③ **从未要求提交租房合同或房租票据** |
| **结果** | 采信员工主张，**认定月工资 5000 元**，判决支付工资差额 |

> ⭐ **可复用**：报销款要认定为工资，抓住"**公司从不真正审核票据**"这一点。
> 反向提醒：如果你每月都在认真提交发票，这个主张会变难。

## 案例 D：合同写 3000，私户每月转 17000 —— 基数按 2 万算

**来源**：北京浩云律师事务所（朝阳区案件，实务归纳）

| 步骤 | 内容 |
|---|---|
| **案情** | 合同约定基本工资 3000 元，实际每月私人账户转账 17000 元，**连续发放 12 个月** |
| **法律定性** | 该"合理避税"约定同时违反个税征管与社会保险的**强制性规定**，属恶意串通损害国家税收与社保基金利益 → **约定无效** |
| **结果** | **认定月平均工资 20000 元**，而非合同约定的 3000 元 |

> ⭐ **可复用**：**连续性**是关键 —— 连续 12 个月固定金额，任何解释都站不住。
> 所以从现在起，把每一次私户转账都记录下来，月份越多越稳。

## 案例 E：持有工资欠条，跳过仲裁直接起诉（程序范例）

**来源**：中工网（四川工会法律援助）

| 步骤 | 内容 |
|---|---|
| **案情** | 公司 2021 年 1 月起拖欠工资，5 月 11 日出具**欠条**："今某公司欠员工辜某 2021 年 1、2、4 月工资共计 12518 元" |
| **程序争议** | 一审法院以"追索劳动报酬纠纷"案由**未经仲裁前置**受理，公司上诉主张程序违法 |
| **法院依据** | 司法解释一**第 15 条**：以工资欠条为证据直接起诉，诉讼请求不涉及劳动关系其他争议的，视为拖欠劳动报酬争议，按**普通民事纠纷**受理 |
| **结果** | 驳回上诉，维持原判 |

> ⭐ **实操价值**：公司拖工资时，**尽量让它出具书面欠条/结算单**，
> 哪怕写"经结算，截至 X 月共欠工资 X 元"。有了这张纸，就能绕开仲裁直接起诉。

## 一句话总结

**钱是从"证据链完整度"和"公司压力值"里来的，不是从法条里来的。**
前 10 天做完三件事 —— 固证、异议、五线递交 —— 后面 80% 的案子会在庭前调解时收掉。
