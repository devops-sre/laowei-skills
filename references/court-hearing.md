# 开庭实战手册

> 前面的文件都在讲"怎么立案"。但**案子是开庭赢的，不是立案赢的**。
> 本文件讲：庭前怎么备、庭上怎么说、对方怎么说你该怎么顶回去。
>
> **劳动法领域被告（用人单位）通常有法务和律师，原告（劳动者）常常是自己上。**
> 这一份就是用来弥补这个不对等的。

---

## 一、开庭前 7 天：准备清单

```
□ 证据册重做一遍：编页码、做目录、每项标注"证明目的"
□ 准备 3 份：仲裁委 1 份、自己 1 份、对方 1 份
□ 音视频证据刻光盘 + 附【文字整理稿】（关键片段标注时间点）
□ 写一份《庭审提纲》（见下），开庭时照着说，不会慌
□ 准备【证据原件】—— 合同、解除通知、EMS 回执必须带原件
□ 预演一遍：把你的核心主张用 3 分钟讲清楚
□ 查好路线，提前 30 分钟到
□ 手机静音、不要录音录像（未经许可庭审录音可能被制止）
```

### 庭审提纲（一页纸，开庭放桌上）

```
【我的核心主张】
  1. 我与 XX 公司存在劳动关系（X 年 X 月 – X 年 X 月，工龄应合并计算）
  2. 公司系违法解除，应支付赔偿金 2N = XXX 元
  3. 公司应支付待岗/降薪工资差额 XXX 元
  ...

【每个主张的证据编号】
  主张1 → 证据 1、2、3
  主张2 → 证据 6、7、10
  ...

【对方的三个可能抗辩 + 我的回击】
  抗辩A：项目结束属客观情况重大变化 → 回击：...
  抗辩B：员工严重违纪         → 回击：...
  抗辩C：已安排调休/已足额支付 → 回击：...

【我方的软肋 + 预备答案】
  软肋：签过一份《离职申请》 → 说明签署背景，主张非真实意思表示
```

## 二、庭审流程与每个环节怎么做

| 环节 | 你要做的事 | 要点 |
|---|---|---|
| **1. 核对身份** | 听清对方到庭人员，**确认对方有无委托律师及权限** | 对方是律师还是 HR，决定你说话的深度 |
| **2. 宣布权利义务 / 问是否申请回避** | 一般不申请 | 除非仲裁员与对方有明显利害关系 |
| **3. 申请人陈述仲裁请求** | ⭐ **照着申请书念，不要临场加戏** | 请求以申请书为准，庭上别改来改去 |
| **4. 被申请人答辩** | **认真记，一字不漏地记** | 对方说的每一句都是线索，也是它自己给自己挖的坑 |
| **5. 举证质证** | ⭐ 见 §三 | 最关键环节 |
| **6. 仲裁员/法官询问** | ⭐ 见 §四 | 问什么答什么，别抢话、别发挥 |
| **7. 法庭辩论** | 围绕争议焦点讲，3~5 分钟 | 见 §五 |
| **8. 最后陈述** | 一句话 | "请求依法支持申请人的全部仲裁请求" |
| **9. 调解** | ⭐ **这是收钱窗口**，见 §六 | 别急着拒绝 |

## 三、⭐ 举证质证 —— 决定胜负的环节

### 3.1 你举证时

**一句话原则：每一项证据都要说出"证明目的"，不要只说"这是我提交的证据"。**

```
❌ 错误："这是我 2024 年的工资流水。"
✅ 正确："证据 2 是申请人 2024 年 1 月至 12 月的银行工资流水，共 3 页，
        证明目的有二：一是申请人解除前 12 个月的实际工资水平为月均 15800 元；
        二是该款项由被申请人的法定代表人个人账户转出，证明公司存在
        拆分工资、体外发薪的情形。"
```

### 3.2 对方质证时（对方会攻击你的证据）—— 用"三性"应对

| 攻击点 | 对方会说 | 你的回应 |
|---|---|---|
| **真实性** | "这是截图，真实性不认可" | "该证据系申请人本人手机录屏取得，原始载体在本庭可当庭出示（当庭演示）。且与证据 X（银行流水/个税记录）相互印证，形成完整证据链。" |
| **合法性** | "录音未经同意，来源不合法" | "该录音系申请人与对方当事人在工作场所的谈话，一方录制，内容涉及本案争议事实，未侵害他人合法权益，也未违反法律禁止性规定，依法可作为证据使用。" |
| **关联性** | "与本案无关" | "该证据直接证明【具体事实】，与第 X 项仲裁请求具有直接关联。" |

> **实务提醒**：仲裁员/法官对**"真实性不认可"**这一句听太多了。
> 只要你能**当庭拿出原始载体**（手机、电脑）演示，配合**其他证据印证**，
> 单纯一句"不认可"基本不成立。

### 3.3 你质证对方证据时 —— 四类常见攻击

```
① 真实性异议：系对方单方制作、未经我方确认、无我方签字
② 合法性异议：规章制度未经民主程序制定、未向我公示告知
③ 关联性异议：与本案争议事实无关
④ 证明力异议：即便属实，也不能证明其主张（比如：调休没有审批记录）
```

**针对公司最常提交的三类证据：**

| 公司证据 | 你的质证要点 |
|---|---|
| **《员工手册》/规章制度** | ⭐ 要求公司证明：①经**民主程序**（职工代表大会或全体职工讨论）；②已**公示或告知**劳动者（有你的签收记录吗？）；③内容是否合理。三缺一 → 不能作为解除依据 |
| **考勤记录** | 是否原始、完整、未经修改？是否只有公司单方系统导出？**为何不提供原始后台数据？** |
| **警告信/违纪处罚单** | 有无送达？有无你的签字？是否**事后补做**？处罚与行为是否相当？ |

## 四、⭐ 仲裁员/法官常问的 10 个问题 + 怎么答

> 答错一个，可能全案崩。全都提前想好。

| # | 问题 | 怎么答 |
|---|---|---|
| 1 | **"你是什么时候知道权利被侵害的？"** | ⚠️ 这是**时效问题**。如实说，但强调："此后我一直通过【微信/EMS/投诉】向公司主张权利，时效已中断，应重新计算。"（准备好中断证据） |
| 2 | **"你为什么没去报到/没去培训？"** | ⭐ 答："我**去了**，有打卡记录/报到声明为证（证据 X）。我只是**书面提出异议**，不同意变更劳动合同，从未拒绝出勤。" |
| 3 | **"你为什么不同意调岗/待岗？"** | "因为改变了劳动合同约定的岗位/地点/薪酬，未经协商。我要求按原合同履行。" |
| 4 | **"这份文件是你签的吗？"** | 看清楚再答。是你签的就承认，但**补充说明签署背景**："字是我签的，但当时是在【待岗期间/被要求当天办完手续/未告知后果】的情况下签的，不是我的真实意思表示。" |
| 5 | **"你的工资到底是多少？"** | ⭐ 答"**应得工资**"，不是到手工资。逐项说明构成：基本 + 绩效 + 补贴 + 提成 + 年终奖分摊，并指向证据 |
| 6 | **"加班是公司安排的吗？"** | "是。有主管在群里的安排记录（证据 X）、有该时段的工作产出（证据 Y）。且考勤记录由公司掌握，公司不提供应承担不利后果。" |
| 7 | **"你有没有向公司主张过？"** | "有。X 月 X 日发过异议函（EMS 单号 X），X 月 X 日发过催告函，均有签收记录。" |
| 8 | **"你还想回去上班吗？"** | ⭐ 决定 2N 还是继续履行。**想拿钱**："鉴于公司已明确拒绝履行且岗位已不存在，我要求支付赔偿金。" **想回去**："我要求继续履行劳动合同。" |
| 9 | **"你有没有在其他单位工作？"** | 如实答。已入职新单位会影响"继续履行"的主张 |
| 10 | **"是否同意调解？"** | ⭐ 答："**同意调解，但要求限期到账。**"（见 §六） |

## 五、法庭辩论 —— 3 分钟讲清楚三件事

```
第一，定性：公司的行为为什么违法。
    "被申请人以项目撤项为由安排待岗、降低工资，既非协商一致，
     也不属于客观情况发生重大变化。客户撤项是被申请人作为项目外包
     企业应承担的经营风险，不能转嫁给劳动者。"

第二，责任：举证责任在被申请人。
    "依据司法解释（一）第四十四条，用人单位作出解除、降薪等决定的，
     由用人单位负举证责任。被申请人未能举证，应承担不利后果。"

第三，金额：每一项都有算式。
    "赔偿金 = 2 × N（X 个月）× 月均工资 X 元 = X 元，
     计算基数依据《劳动合同法》第四十七条，采用解除前 12 个月应得工资。"
```

**三个不要**：不要讲情绪、不要重复车轱辘话、不要攻击对方人身。

## 六、⭐ 调解环节 —— 这是收钱窗口，不是妥协

**仲裁庭先行调解是法定环节。数据显示大量案件在这一步解决。**

```
你的三步报价：
  开口：激进档（全部项目，按最有利口径）
  落点：合理档
  底线：保守档

三个必须坚持：
  1. 钱到账才签字
  2. 调解书写明【逾期不付按全额 2N 执行】的违约条款
  3. 离职证明、社保公积金转移一并写进协议

一个可以灵活：
  金额可以让步，条款不能让步
```

**当场话术**：
> "我同意调解，接受 X 元。条件是三日内到账，且调解书载明逾期按全额 2N 执行。
> 另外离职证明必须只写法定四项内容，并在付款当日出具。钱到账我再签字。"

## 七、⭐ 公司常见抗辩 × 你的回击（完整对照表）

> 这是本文件最值钱的部分。对方说上一句，你直接接下一句。

| 公司的抗辩 | 你的回击（可直接念） |
|---|---|
| **"项目结束属于客观情况发生重大变化"** | "部门整体外包、项目撤项不构成客观情况重大变化，北京顺义法院已有判决（C3）。且公司仍在正常经营、持续承接项目，不存在致使劳动合同无法履行的情形。" |
| **"我们是依法安排待岗"** | "客户撤项是用人单位应承担的经营风险。A公司案的判决明确：外包企业对此'理应有相应处理方案'，未协商径行安排待岗缺乏理据；且待岗通知未载明期限、工资标准断崖式下跌缺乏依据（C39）。" |
| **"员工严重违反规章制度"** | "请对方举证：①该行为确实存在；②规章制度经民主程序制定并已公示；③该行为在制度中被界定为'严重违纪'；④处罚与过错相当。四者缺一，解除违法（C1、C2）。" |
| **"员工绩效考核末位/不胜任"** | "最高法指导案例 18 号明确：**考核居于末位不等同于'不能胜任工作'**，不符合单方解除的法定条件。且即便不能胜任，也须**先培训或调岗**，仍不能胜任才可解除，并须提前 30 日通知或支付代通知金。" |
| **"已安排调休，不应支付加班费"** | "调休须按公司考勤制度走报批流程。请对方出示审批记录。B案中公司同样主张调休，因**无法证明经过正常审批流程**而未被采信（C40）。" |
| **"工资已足额发放"** | "请对方说明：个税申报数、社保基数、银行实收数三者为何不一致？本人个税申报记录显示月均 X 元，而社保按 X 元申报（证据 X）。" |
| **"我们只是派遣/外包，你不是我们员工"** | "本人的日报、周报、绩效评分、请假审批均由贵司主管执行，工牌、工位、系统账号均属贵司，构成事实劳动关系/混同用工。依司法解释（二）第三条，可请求关联单位共同承担责任（C5、C30）。" |
| **"是员工自己辞职的"** | "请对方出示本人签字的辞职申请。事实上本人发出的是《被迫解除劳动合同通知书》，依据第三十八条，系依法行使解除权，公司仍应支付经济补偿。" |
| **"已过仲裁时效"** | "本人于 X 月 X 日、X 月 X 日通过 EMS 及微信向公司主张权利，并向劳动监察部门投诉，依《劳动争议调解仲裁法》第二十七条第二款，**时效中断并重新计算**。" |
| **"公司经营困难，无力支付"** | "经营困难不是免除法定责任的理由。公积金缴存具有强制性，不得以经营困难为由拒绝履行（C22）。" |
| **"员工给公司造成了损失"** | "请对方举证：损失的实际发生、具体数额、与本人行为的因果关系，以及公司规章制度的依据。用人单位对此负举证责任。" |
| **"你已经签了离职协议"** | "该协议系在待岗期间、未告知法律后果的情况下签署，且其中放弃社保、公积金的条款违反法律强制性规定，**该部分无效**。社保公积金我已另行向行政部门投诉。" |

## 八、庭审禁忌（一个都别犯）

1. ❌ **说谎** —— 一处被拆穿，全案证据可信度崩塌
2. ❌ **情绪化、指责对方人品** —— 仲裁员只关心事实和法律
3. ❌ **临场改变仲裁请求** —— 以申请书为准
4. ❌ **没听清就回答** —— "请再说一遍"不丢人
5. ❌ **和对方当事人争吵** —— 有话对仲裁员说
6. ❌ **庭上提交新证据却不备份** —— 会被拒绝或延期
7. ❌ **拒绝调解时说"绝不调解"** —— 说"同意调解，但要求限期到账"

## 九、开庭后

```
□ 当场核对笔录，确认无误再签字
   ⚠️ 笔录签了字就很难翻。关键表述被记错，务必要求更正后再签
□ 记下仲裁员说的"本案争议焦点"
□ 等裁决（45 日内，可延 15 日）
□ 若裁决支持，等 15 天起诉期过后申请执行
□ 若裁决不支持或部分支持，15 日内决定是否起诉
```
