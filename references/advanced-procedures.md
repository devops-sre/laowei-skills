# 进阶程序手册

> 前几份文件解决"怎么立案、怎么开庭"。这份解决四件更细但会决定成败的事：
> ①**你拿不到的证据怎么调出来**；②**人证怎么用**；
> ③**公司反手申请撤销终局裁决怎么顶**；④**一审输了还有没有救**。

---

## 一、⭐ 你拿不到的证据，怎么让它"必须交出来"

> **核心思路**：不要自己死磕。**法律把"调取"的义务放在公司身上。**
> 劳动者最常见的困境是"考勤在公司系统里、工资台账在财务手里" ——
> 但这两样东西，**法律明确规定由用人单位掌握，公司必须提供**。

### 1.1 三条法定通道（按优先级用）

| 通道 | 依据 | 怎么用 | 效果 |
|---|---|---|---|
| **① 申请仲裁庭责令公司提供** | 《劳动争议调解仲裁法》**第 39 条第 2 款**：劳动者无法提供由用人单位掌握管理的与仲裁请求有关的证据，**仲裁庭可以要求用人单位在指定期限内提供**；**用人单位在指定期限内不提供的，应当承担不利后果** | 提交《责令提供证据申请书》，列明要公司提供什么（考勤原始后台数据、工资台账、绩效评分依据、规章制度民主程序记录） | ⭐ 公司不交 = **直接推定你的主张成立** |
| **② 诉讼阶段申请法院调查令** | 民事诉讼法；律师持令调取 | 委托律师申请，调取**银行流水、社保缴费记录、监控录像、第三方平台数据** | 对方第三人（银行、平台）必须配合 |
| **③ 申请仲裁委/法院调查收集** | 因客观原因不能自行收集的（保存在社保局、第三方支付机构的材料） | 提交《调查取证申请书》 | 由办案机关出面 |

> **原话（开庭/书面可直接用）**：
> "考勤记录及工资台账属于由被申请人掌握管理的证据，依据《劳动争议调解仲裁法》
> 第六条、第三十九条，申请仲裁庭责令被申请人在指定期限内提供；
> 逾期不提供的，请依法承担不利后果，并采信申请人主张的工资标准与加班事实。"

### 1.2 明确由**公司负举证责任**的六类

| # | 情形 |
|---|---|
| 1 | 因用人单位作出的**开除、除名、辞退、解除劳动合同、减少劳动报酬、计算工作年限**等决定发生的争议 |
| 2 | **确认劳动关系**争议中：工资支付凭证（工资发放花名册）、社保缴费记录、招工登记表/报名表、**考勤记录** |
| 3 | 用人单位**未按约定支付劳动报酬、拒缴社保、不提供劳动条件**，劳动者据此解除发生的争议 |
| 4 | **工伤**争议：职工认为是工伤，用人单位不认为是工伤的 |
| 5 | **加班费**：劳动者有证据证明用人单位掌握加班事实存在的证据，用人单位不提供的，承担不利后果 |
| 6 | 规章制度的**民主程序与公示告知**证据 |

### 1.3 ⭐ 一条超好用的规定

**《工资支付暂行规定》第 6 条**：用人单位必须书面记录支付劳动者工资的数额、时间、
领取者的姓名以及签字，并**保存两年以上备查**。

```
→ 公司说"工资台账找不到了"？
→ 那是它自己违反法定义务，不利后果由它承担
→ 你可以主张：因公司未依法保存，应按【你方证据】（个税/银行流水）认定工资标准
```

### 1.4 ⚠️ 反向警告：这四类证据**不能单独定案**

司法解释规定，以下证据**不能单独作为认定案件事实的根据**：

```
① 当事人的陈述（你自己的说法）
② 与一方当事人有利害关系的证人出具的证言（在职同事的证言有此风险）
③ 存有疑点的视听资料、电子数据（截图、未公证的录音）
④ 无法与原件、原物核对的复制件、复制品
```

> ⭐ **这就是为什么前面反复强调**：
> **录屏（不是截图）+ 原始载体（不是复制件）+ 其他证据印证（不是孤证）**。
> 不是形式主义，是直接决定证据有没有用。

**同理**：以**严重侵害他人合法权益、违反法律禁止性规定、严重违背公序良俗**的方法
取得的证据，**不得作为认定案件事实的根据**（这也是取证红线的法律依据）。

## 二、证人出庭 —— 人证怎么用才有效

### 2.1 程序要点

```
□ 在【举证期限届满前】提出申请，经仲裁委/法院许可
□ 证人必须【亲自到庭】接受询问 —— 只交书面证言，证明力大打折扣
□ 证人【不得旁听】庭审；询问证人时，其他证人不得在场（隔离询问）
□ 可申请证人签署《如实陈述保证书》
□ 附证人身份证明 + 工作证/工牌等证明其身份与在职期间的材料
```

### 2.2 ⭐ 证人的选择（实务经验）

| 优先级 | 证人 | 说明 |
|---|---|---|
| 🥇 | **离职同事** | 无顾忌，证言自由度高 |
| 🥈 | **在职同事** | 证明力高于离职者，但**普遍怕报复** |
| 🥉 | **项目甲方的对接人** | 证明甲方实际管理，价值极高，但难请 |
| ❌ | 你的亲属、与你有直接利害关系的人 | 证明力弱，可能被认定"有利害关系" |

**在职同事不敢出庭怎么办**
```
1. 先请【已离职】的同事 —— 顾虑少，且能说清当时的情况
2. 在职同事可提供【书面证言】—— 证明力弱，但"聊胜于无"，
   配合其他客观证据（打卡记录、群聊截图）使用
3. 向仲裁庭说明情况，申请【调取客观证据】替代（考勤系统、监控、审批流）
4. 请工会出面 —— 企业工会有权要求用人单位提供材料（《工会法》）
```

### 2.3 书面证言的格式要点

```
证人证言

本人【姓名】，身份证号【          】，联系电话【        】。
本人于【    年  月】至【    年  月】在【公司全称】任职，岗位【    】，
与申请人【姓名】系同事关系。

本人可以证明以下事实：
1. 【时间】，本人亲眼见到/亲身经历【具体事实】；
2. 【时间】，【具体事实】；
3. 申请人的日常工作由【甲方主管姓名】安排，绩效由【  】评定。

以上陈述属实，本人愿意出庭作证，并愿承担相应法律责任。

                                  证人（签名+按手印）：
                                  身份证复印件：（附后）
                                  20XX 年 X 月 X 日
```

## 三、鉴定与审计 —— 用得少但关键时刻管用

| 情形 | 申请什么 | 说明 |
|---|---|---|
| 笔迹真伪争议（你否认签过某文件） | **笔迹鉴定** | 你否认签名真实性时可申请，由公司或鉴定机构提供比对样本 |
| 工资构成/加班时长计算复杂 | **司法审计** | 涉及长期、大量数据的案件，可申请对工资台账审计 |
| 公章真伪 | **印章鉴定** | 怀疑公司伪造文件时 |
| 电子数据真实性争议 | **电子数据鉴定** | 对方质疑你的聊天记录/录音时使用 |

**要点**
- 一般需**预缴鉴定费**，由申请方先行垫付，最终由败诉方承担
- 鉴定期间**不计入审理期限**
- 申请要在举证期限内提出，写明鉴定事项与目的

## 四、⭐ 公司反手申请撤销终局裁决 —— 怎么顶回去

### 4.1 规则先搞清楚

**《劳动争议调解仲裁法》第 49 条**：用人单位有证据证明终局裁决有下列情形之一，
可以自收到裁决书之日起 **30 日内**向**劳动争议仲裁委员会所在地的中级人民法院**
申请**撤销**裁决：

```
(一) 适用法律、法规确有错误的
(二) 劳动争议仲裁委员会无管辖权的
(三) 违反法定程序的
(四) 裁决所根据的证据是伪造的
(五) 对方当事人隐瞒了足以影响公正裁决的证据的
(六) 仲裁员在仲裁该案时有索贿受贿、徇私舞弊、枉法裁决行为的
```

**三条关键规则**
1. ⚠️ **公司不能向基层法院起诉** —— 终局裁决下，公司只能走"中院撤销"。
   若它向基层法院起诉，**法院应裁定驳回起诉**
   （威信县法院案例：公司起诉被驳回，告知应向中院申请撤销）
2. **法院应组成合议庭**审查核实（不是独任，程序上对你有利）
3. ⭐ **司法解释（一）第 21 条**：劳动者向基层法院起诉、用人单位向中院申请撤销的，
   **中级人民法院应当不予受理** —— 也就是说，**你先起诉，它的撤销申请就进不来**

### 4.2 你的应对（四步）

```
① 收到终局裁决后，先【判断要不要起诉】
   —— 满意 → 不起诉，等 30 天撤销期过后申请执行
   —— 不满意 → 【15 日内】向基层法院起诉 ⭐ 这一步同时封死公司的撤销之路

② 若公司已申请撤销，你会收到中院通知 —— 【必须答辩】
   答辩核心：逐条反驳它主张的六种情形
   · "适用法律法规错误" → 说明裁决适用法律正确，它只是对事实认定有异议，
     而【事实认定不属于撤销事由】
   · "违反法定程序" → 要求它说明具体违反了哪条程序，举证责任在它
   · "证据伪造/隐瞒证据" → 要求它指出是哪一份证据、如何伪造
   ⭐ 撤销事由是【封闭列举】的，它说不出具体情形，就撤不掉

③ 强调【撤销事由的举证责任在公司】，且标准是"有证据证明"

④ 若真的被撤销 —— 你还有路：
   自收到裁定书之日起【15 日内】就该劳动争议事项向人民法院起诉
   （撤销不等于你输了，只是回到诉讼程序）
```

### 4.3 一个重要的策略提示

**终局裁决的"双刃"性质**：

| 对你 | 对公司 |
|---|---|
| 裁决作出即生效，你可**直接申请执行** | ❌ 不能起诉，只能申请撤销（事由极窄） |
| 你对裁决**不服仍可起诉**（15 日内） | 只能等 30 天撤销期 |

> ⭐ **所以终局裁决对你整体有利**。但要注意：若同一裁决**同时包含终局和非终局事项**，
> 依司法解释（三）第 14 条，**整体按非终局处理** —— 公司就能起诉了。
> **所以申请时，要么全部控制在门槛内，要么就别指望终局。**

## 五、一审输了：上诉与再审

### 5.1 上诉（常规路径）

```
期限：收到判决书之日起【15 日内】提交上诉状
审限：二审 3 个月
要点：
  ⭐ 上诉状要【针对一审判决的错误】写，不要复述一遍事实
  · 事实认定错误 → 指出哪项事实认定与证据不符
  · 适用法律错误 → 指出援引法条错误
  · 程序违法     → 指出一审违反的法定程序
  · 举证责任分配错误 ← 劳动争议里最常见的上诉理由
```

> **劳动争议最常见的上诉理由**：一审把**本应由用人单位承担的举证责任**错配给了劳动者。
> 例如："一审以申请人未能证明加班事实为由驳回，但考勤记录由被申请人掌握，
> 被申请人拒不提供，应依法承担不利后果，一审举证责任分配错误。"

### 5.2 再审（非常规，但有个出口）

二审终审后仍不服 → 可申请**再审**（审判监督程序）。
门槛高（需符合民事诉讼法第 207 条等规定的情形），实务成功率低。

**更现实的替代路径**：
```
· 向同级人民检察院申请【法律监督】（检察建议 / 抗诉）
· 通过【信访、人大、政协】等渠道反映（不直接改判，但有时推动复查）
· 若发现新证据 → 及时提交
```

### 5.3 一句大实话

> **劳动争议的胜负，八成在仲裁和一审就定了。**
> 二审改判率不高，再审更低。**所以精力要前移** ——
> 把证据做扎实、把请求写准确、把举证责任的主张在**一审就明确提出来**。
> 等到上诉再补证据，往往来不及。

## 六、执行阶段的补充动作

（基础内容见 `defense-and-risk.md` §八）

```
□ 申请执行后，主动向法院提交《被执行人财产线索表》
   —— 新账户、应收账款、对外投资、知识产权、分支机构
□ 关注【到期债权】：外包公司的资产常在甲方的应付款里
   → 可申请对第三人（甲方）的【到期债权】执行
□ 申请【悬赏执行】（部分地区支持）
□ 申请【委托执行】（财产在外地时）
□ 对执行行为有异议 → 提出【执行异议】
□ 公司转移财产 → 查【撤销权】/ 追加被执行人
□ 有能力执行而拒不执行 → 【拒不执行判决、裁定罪】（刑法 313 条）
```

## 附录：三份申请书要点（可照此写）

```
【责令提供证据申请书】
  请求：请求仲裁庭责令被申请人在指定期限内提供下列证据：
        1. 申请人 20XX 年 X 月至 20XX 年 X 月的【考勤原始记录】；
        2. 同期【工资支付台账】（含工资构成、奖金、补贴、加班费明细）；
        3. 《员工手册》经职工代表大会或全体职工讨论的【会议记录】
           及向申请人公示告知的【签收记录】；
        4. 申请人 20XX 年度【绩效考核评分依据】。
  理由：上述证据属由被申请人掌握管理的证据，申请人无法自行取得。
        依据《劳动争议调解仲裁法》第六条、第三十九条，被申请人应当在
        指定期限内提供；逾期不提供的，应承担不利后果。

【证人出庭作证申请书】
  证人姓名、身份证号、联系方式、与本案的关系
  拟证明的事实：（逐条列明）
  （附证人书面证言及身份证明）

【调查取证申请书】
  请求调取：XX 银行 / XX 社保中心 / XX 平台保存的……
  理由：申请人因客观原因不能自行收集，依据《劳动争议调解仲裁法》
        相关规定申请调查收集。
```
