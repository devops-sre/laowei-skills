# 税务举报实操手册

> 依据：**《税收违法行为检举管理办法》（国家税务总局令第 49 号，2020 年 1 月 1 日施行）**
> 及《检举纳税人税收违法行为奖励暂行办法》。
>
> 税务线是外包维权里**杀伤力最大、但最不可逆**的一条。
> 本手册讲清楚：什么能举报、实名还是匿名、举报信怎么写、证据怎么组织、
> 多久有结果、能不能拿奖励、会不会被报复。

---

## 一、先搞清楚：什么能举报，什么不能（很多人搞错了）

### 1.1 受理范围（办法第 3 条）

```
涉嫌偷税（逃避缴纳税款）
逃避追缴欠税
骗税
虚开、伪造、变造发票
其他与逃避缴纳税款相关的税收违法行为
```

### 1.2 ⚠️ 不予受理的三种情形（办法第 17 条）—— 第二条是关键

| 情形 | 说明 |
|---|---|
| ① 无法确定被检举对象，或不能提供税收违法行为线索 | 所以举报信必须写清公司全称、地址、违法线索 |
| ② **检举事项已经或者依法应当通过诉讼、仲裁、行政复议以及其他法定途径解决的** | ⭐ **你和公司的劳动争议本身（欠薪、赔偿金）不在税务受理范围**，那是仲裁的事 |
| ③ 对已查结的同一事项再次检举，无新的有效线索 | 别反复投同一份材料 |

> ⭐ **最常见的错误**：把"公司欠我 8 万赔偿金"写成税务举报 → 不予受理。
>
> **正确写法**：举报的是**公司的税收违法行为**，不是你的个人纠纷：
> "该公司长期通过法定代表人个人账户向员工发放工资，未并入工资薪金申报个人所得税，
> 且未按实际工资申报社保缴费基数，涉嫌少缴个人所得税、企业所得税及社会保险费。"
>
> 你的赔偿金问题走仲裁，这两条线**并行不悖**，但**诉求不要混在一起写**。

### 1.3 外包场景里，真正值得举报的四件事

| 举报事项 | 涉嫌什么 | 证据 |
|---|---|---|
| **① 私户/微信发工资**（法人、财务个人卡转） | 少代扣代缴个税；少缴社保费 | 银行流水（显示付款方）、个税申报明细 |
| **② 发票报销抵工资** | 以报销掩盖工资性质；可能涉虚开发票 | 月度固定报销审批 + 到账流水 |
| **③ 个税申报数远低于实际工资** | 少代扣代缴个税 | 个税 App 明细 vs 银行实收 |
| **④ 社保按最低基数申报**（与个税申报数不一致） | 少缴社保费（社保已划归税务征收） | 社保缴费明细 vs 个税申报明细 |

> ⭐ **第 ④ 项特别有价值**：金税四期实现**个税申报、社保缴纳、银行流水、企业工资成本四流交叉比对**。
> 实务口径：个税工资与社保基数**差异 >10% 即触发预警工单**，无需人工抽查。
> 也就是说，你的举报不是"大海捞针"，而是**系统里已经有标记，你只是推它一把**。

## 二、实名还是匿名（这是个真实的选择题）

### 2.1 差别对照

| | **实名检举** | **匿名检举** |
|---|---|---|
| 受理 | ✅ 必须受理 | ✅ 同样必须受理（办法第 10 条：实名与匿名均须受理） |
| **答复处理结果** | ✅ 可以要求答复 | ❌ 无 |
| **举报奖励** | ✅ 可申请 | ❌ **不予奖励**（奖励办法第 3 条） |
| **接收回执** | ✅ 来访可要求出具 | ❌ |
| 被泄露风险 | 有严格保密规定（见 §八） | 更低 |

### 2.2 ⚠️ 一个技术细节：电话不能实名

**办法第 13 条**：以电话形式要求实名检举的，税务机关应当告知检举人**采取来信、网络、传真形式**进行检举。
**未采取上述形式的，视同匿名检举。**

```
所以：想拿奖励、想跟进结果 → 必须走【网络/书信/来访】，并在材料中附上
     【居民身份证复印件】。只打 12366 电话，默认按匿名处理。
```

**多人联名**：应当确定**第一联系人**；未确定的，以第一署名为第一联系人。

### 2.3 我的建议

| 你的目的 | 建议 |
|---|---|
| 主要是**施压**、不想暴露 | **匿名**（网络提交即可，不必附身份证） |
| 想**跟进结果**、想拿奖励 | **实名**（网络提交 + 附身份证复印件 + 书面举报信） |
| 已经离职、不怕公司知道 | 实名，效果更好（可答复、可奖励） |
| **还在职** | ⚠️ **慎重** —— 见 §八 与 §九 |

## 三、举报信怎么写（六要素）

**办法第 10 条要求的最低要素**：被检举人的**名称（姓名）**、**地址（住所）**、
**税收违法行为线索**。

**鼓励提供**：统一社会信用代码、法定代表人/实际控制人信息、其他相关证明资料。
**鼓励提供书面检举材料**。

### 3.1 六要素清单

```
① 被检举人全称（与营业执照一致）+ 统一社会信用代码
② 被检举人注册地址 + 实际经营地址
③ 法定代表人 / 实际控制人姓名
④ 违法行为的【具体描述】：什么时间、什么方式、涉及多少人、大致金额
⑤ 违法线索的【证据清单】（附复印件）
⑥ 明确的请求：请求依法立案检查
```

⭐ **写法要点**：
- **只写事实和线索，不下法律结论**（不要写"该公司构成偷税罪"，写"涉嫌未足额代扣代缴"）
- **能量化的尽量量化**（涉及人数、月份数、金额区间）
- **不要情绪化、不要写个人恩怨**
- **不要把你自己的劳动争议混进来**（见 §1.2）

### 3.2 模板

```

检举人：【姓名】，身份证号：【            】，
        联系电话：【        】，通讯地址：【              】
        （实名检举请附：居民身份证复印件）
        【若为匿名，此栏写"匿名检举"，可不提供身份信息】

被检举人：【公司全称】
        统一社会信用代码：【                    】
        注册地址：【                            】
        实际经营地址：【                        】
        法定代表人：【      】，实际控制人：【      】

【多人联名时：第一联系人为【姓名】】

具体情况如下：

（一）通过个人账户发放工资，未并入工资薪金申报个人所得税
    20XX 年 X 月至 20XX 年 X 月期间，被检举人通过【法定代表人/财务负责人
```

## 四、证据怎么组织（⚠️ 有个硬红线）

### 4.1 ⭐ 奖励办法第 3 条：这四种情况【不予奖励】

```
(一) 匿名检举，或者检举人无法证实其真实身份的
(二) 检举人【不能提供税收违法行为线索】，或者
     采取【盗窃、欺诈或者法律、行政法规禁止的其他手段】获取税收违法行为证据的
(三) 检举内容含糊不清、缺乏事实根据的
(四) 检举人提供的线索与税务机关查处的税收违法行为无关的
```

> ⚠️ **第（二）项是硬红线**：**用非法手段拿到的证据，不但不给奖励，还可能担责。**
> 所以 —— 不要用他人账号登录、不要破解系统、不要偷拿公司财务账册。
> **只用你自己合法持有的材料**：你的银行流水、你的个税明细、你的社保明细、
> 你自己参与的聊天记录。这些足够，而且干净。

### 4.2 最有说服力的三份材料

```
① 银行流水（银行 App 导出带电子章）—— 证明实际收到的金额与付款方
② 个人所得税 App「收入纳税明细」—— 公司自己申报的数，无法抵赖
③ 社保缴费明细 —— 与 ①② 一比对，差额一目了然
```

> **这三份都是你自己就能拿到的**，不需要任何公司权限，也不需要任何灰色手段。

### 4.3 证据组织成对照表（强烈推荐）

| 月份 | 公账到账 | 私户到账 | 实收合计 | 个税申报 | 社保基数 |
|---|---|---|---|---|---|
| 2025-01 | 4,000 | 11,000 | 15,000 | 4,000 | 4,000 |
| … | | | | | |

一张表胜过十页说明。

## 五、渠道与流程

### 5.1 五个渠道

| 渠道 | 说明 | 能否实名 |
|---|---|---|
| **① 网络**（推荐） | 各省税务局官网"税收违法行为检举"入口 / 12366 平台 | ✅ 可（附身份证复印件） |
| **② 书信** | 邮寄至税务机关举报中心 | ✅ 可 |
| **③ 来访** | 到税务机关检举接待场所，**可当场要求出具接收回执** | ✅ 可（需带原件+复印件） |
| **④ 传真** | | ✅ 可 |
| **⑤ 电话 12366** | 便捷，但**默认按匿名处理** | ❌ 不能实名 |
| **⑥ 个税 App 申诉** | 对不实申报记录发起申诉（"收入不符"/"被任职"） | 另一条路，见下 |

### 5.2 ⭐ 第六条：个税 App 申诉（成本最低的一条）

```
路径：个人所得税 App → 办&查 → 收入纳税明细查询 → 选择某条记录 → 申诉
可选："从未在职"（被任职）/ "收入不实"

效果：税务机关会向扣缴义务人（公司）核实 → 公司必须作出说明
```

> **这条最轻、最快、可逆性相对高**，适合作为**先手**，
> 正式的税务违法检举作为**后手**。

### 5.3 流程与时限（办法第 22 条）

```
你提交
  ↓
举报中心接收 → 审查是否受理（第 17 条三种情形不予受理）
  ↓  自【受理之日起 15 个工作日内】完成分级分类处理
查处部门
  ↓  自【收到检举材料之日起 3 个月内】办理完毕
      （案情复杂可以延期）
  ↓
查结 → 实名检举人可要求答复结果 → 可申请奖励
```

**分级分类（第 20 条）**
```
(一) 内容详细、线索清楚、证明资料充分    → 稽查局【立案检查】
(二) 内容与线索较明确但缺少必要证明资料  → 稽查局【调查核实】
(三) 对象明确但内容不清、线索不明        → 【暂存待查】，建议你补充
(四) 已受理未查结再次检举                → 合并处理
```

> ⭐ **所以：证据充分与否，直接决定是"立案检查"还是"调查核实"甚至"暂存待查"。
> 别空口举报，把三份材料（流水+个税+社保）备齐再提交。**

## 六、奖励

**条件**：检举事项**经查证属实**，为**国家挽回或者减少损失**的，对**实名检举人**给予相应奖励。

**怎么拿**
```
1. 必须是【实名】检举
2. 需要【书面申请】（不是自动给）
3. 依据：《检举纳税人税收违法行为奖励暂行办法》
4. 按【贡献大小】给，具体标准由财政部、国家税务总局规定
```

**⚠️ 四种不予奖励**（见 §4.1）

> **实务提醒**：奖励金额通常是查补税款的一定比例且有上限，
> **不要指望靠奖励发财**。税务举报的真正价值是**施压**，不是奖金。
> 而且部分地区对小额案件的奖励执行较松 —— 浙江 12366 曾答复"区县查处的轻微
> 违法案件无奖励标准"。**心态放在"推动查处"上。**

## 七、保密与防报复

**办法第 38 条（对你极其有利）**
```
(一) 受理、登记、处理及查处各环节严格保密，不得私自摘抄、复制、扣压、销毁检举材料
(二) 严禁泄露检举人的姓名、身份、单位、地址、联系方式；
    严禁将检举情况透露给被检举人及与案件查处无关的人员
(三) 调查核实和立案检查时【不得出示检举信原件或者复印件】，不得暴露检举人的有关信息；
    【对匿名的检举书信及材料，除特殊情况外不得鉴定笔迹】
(四) 宣传报道和奖励检举有功人员，未经检举人【书面同意】，不得公开其信息
```

**办法第 40 条**：税务机关工作人员**打击报复检举人**的，视情节和后果依法给予行政处分；**涉嫌犯罪的移送司法机关**。

> ⭐ **所以：公司原则上不会知道是谁举报的**，尤其在"公司同类用工人数多"的情况下。
> **外包公司往往几十上百人情况相同，你的举报只是其中一例，被识别出来的概率很低。**

**降低风险的三个做法**
1. 选择**匿名**（最保险，代价是没有结果反馈与奖励）
2. 举报内容**只写你自己的情况**，不要写"我知道其他同事也…"—— 写得越具体越容易被锁定
3. 举报前**先完成取证和仲裁立案**，避免公司报复性销毁证据或反咬

## 八、⚠️ 战术定位：这是不可逆的一步

### 8.1 为什么不可逆

```
你举报 → 税务机关立案 → 公司被要求说明、补缴、接受处罚
       → 即便你后来撤诉、和解，税务案件【不会因为你撤诉而停止】
       → 公司在税务上留下了痕迹
```

**后果**
- 谈判余地显著变小（公司会觉得"反正已经被查了，没必要再给你好处"）
- 若你在职，关系基本无法修复
- 若你是被动配合过工资拆分，可能**被要求补缴个税及滞纳金**（见 comp-formulas §一）

### 8.2 建议的出手顺序

```
【第一波】低成本、可逆
  · 异议函、催告函（留痕）
  · 劳动仲裁立案
  · 劳动监察 12333 投诉
  · 公积金 12329 投诉
  · ⭐ 个税 App 申诉（成本最低的税务动作）

【第二波】不可逆，作为后手牌
  · 税务违法检举（12366 / 官网）
  · 明确告知对方："如果今天谈不拢，我明天就提交。"

【关键】
  先立案、先谈第一轮，把税务举报握在手里当筹码，
  谈崩了再打出去 —— 而不是一上来就全部打完。
```

### 8.3 谈判话术

> "我的赔偿金是 8 万，这个数字我算过，有法律依据。另外我手里有个税申报记录和
> 银行流水，能看出来公司是按什么基数在申报。这个东西一旦交给税务，
> 要补的不只是我一个人的。我不希望走到那一步，但今天如果谈不下来，
> 我没有别的选择。"

**⚠️ 注意分寸**：说明事实和后果即可，**不要说"你不给钱我就举报"** ——
那可能被认定为**敲诈勒索**。正确表述是"我将依法向税务机关反映情况"。

## 九、FAQ

| 问题 | 答案 |
|---|---|
| 举报后多久有结果？ | 举报中心 **15 个工作日内**完成分级分类处理；查处部门 **3 个月内**办结，复杂可延期 |
| 公司会知道是我吗？ | 原则不会。办法明确禁止泄露检举人信息，且不得出示检举信原件；匿名材料一般不鉴定笔迹 |
| 匿名举报有用吗？ | 有用，同样必须受理并查处，只是**不答复结果、不给奖励** |
| 能拿到多少钱奖励？ | 依查补税款和贡献大小，需**书面申请**；不要抱过高期望，价值在施压不在奖金 |
| 我在职能举报吗？ | 可以，但**强烈建议先完成取证与仲裁立案**再出手 |
| 我配合过工资拆分，举报会害了自己吗？ | ⚠️ 有被追缴个税及滞纳金的风险。建议先留存"公司要求我这么做"的证据，证明被动配合 |
| 只打电话 12366 够吗？ | 够受理，但**默认按匿名**，拿不到结果反馈与奖励 |
| 举报材料能要回来吗？ | **不能**。办法第 25 条：已接收的检举材料原则上不予退还 |
| 税务举报和劳动仲裁冲突吗？ | 不冲突，但**诉求要分开写** —— 税务只管公司违法，仲裁管你的钱 |
